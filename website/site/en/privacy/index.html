3. Server log files

For every request our web server logs the IP address, time, requested address, status code, transferred bytes, browser identifier and referring page. We use this data to keep the website secure and running, to find errors, and in aggregated form to test the OpenSpider log file analysis with real data. It is not combined with other data sources. Logs are rotated weekly and deleted after nine weeks at the latest. Legal basis: Art. 6 (1) (f) GDPR (legitimate interest in secure and error-free operation).
