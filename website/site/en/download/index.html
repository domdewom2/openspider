Minimum platforms

macOS

macOS 13 or later, Apple Silicon (arm64) or Intel (x86_64).

Windows

Windows 10 version 1809 or later, or Windows 11, x64. Windows on ARM runs the x64 version under emulation.

Linux: CLI

There is deliberately no Linux desktop app. The core and CLI support Linux x86_64 with glibc.
