Windows on ARM uses the x64 installer under emulation, not a native ARM build. Linux supports the core and CLI only. Linux desktop, .deb/.rpm and arm64 releases are unsupported.

MSI is also built for Windows x64. The generated MSI filename includes a language suffix and follows the pattern below. Copy the exact filename from the release into the MSI URL template. Do not derive it from the NSIS filename. MSI uses a numeric product version (beta/RC mapping), while the release tag uses SemVer.

OpenSpider_<build-version>_x64_<language>.msi

MSI URL template (replace entire asset name): https://github.com/domdewom2/openspider/releases/download/vVERSION/MSI_ASSET_NAME.msi

Verify SHA-256

The release provides SHA256SUMS in the same GitHub release. It covers the collected release assets. Download the checksum file and your installer/archive from the same approved release; compare the filename and full digest. Do not install on mismatch. Checksums verify integrity; they do not replace code-signature verification.

SHA256SUMS · URL template: https://github.com/domdewom2/openspider/releases/download/vVERSION/SHA256SUMS

# macOS
shasum -a 256 OpenSpider_VERSION_aarch64.dmg
# Linux (place the downloaded archive and SHA256SUMS together)
sha256sum --ignore-missing -c SHA256SUMS
# Windows PowerShell
Get-FileHash .\OpenSpider_VERSION_x64-setup.exe -Algorithm SHA256

On macOS and Windows compare the result with the matching line in SHA256SUMS. On Linux check that the selected archive is actually reported OK; missing assets are skipped.
