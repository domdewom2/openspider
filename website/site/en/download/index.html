Other files

The buttons above download versionless copies (OpenSpider-macOS.dmg, OpenSpider-Windows-Setup.exe), byte-identical to the versioned files of the same release. Every release also contains the following files; replace VERSION with the release version (for example 1.0.0-beta.3):

  • macOS 13+ · universal DMG: OpenSpider_VERSION_universal.dmg
  • Windows x64 · per-user setup (NSIS): OpenSpider_VERSION_x64-setup.exe
  • Windows x64 · per-machine MSI for software distribution: OpenSpider_<build-version>_x64_<language>.msi (copy the exact name from the release; MSI may use a numeric product version)
  • Command line: openspider_VERSION_darwin-universal.tar.gz (macOS), openspider_VERSION_windows-x86_64.zip (Windows), openspider_VERSION_linux-x86_64.tar.gz (Linux x86_64, glibc)
  • Checksums: SHA256SUMS. Only for automatic app updates: latest.json, latest-beta.json, *.app.tar.gz and *.sig.

URL template: https://github.com/wojcikdominik/openspider/releases/download/vVERSION/FILENAME

Windows on ARM uses the x64 installer under emulation, not a native ARM build. Linux supports the core and CLI only. Linux desktop, .deb/.rpm and arm64 releases are unsupported.

Verify SHA-256

SHA256SUMS is part of the same GitHub release and covers every release file, including the versionless copies. Download the checksum file and your installer/archive from the same release; compare the filename and full digest. Do not install on mismatch. Checksums verify integrity; they do not replace code-signature verification.

# macOS
shasum -a 256 OpenSpider-macOS.dmg
# Linux (place the downloaded archive and SHA256SUMS together)
sha256sum --ignore-missing -c SHA256SUMS
# Windows PowerShell
Get-FileHash .\OpenSpider-Windows-Setup.exe -Algorithm SHA256

On macOS and Windows compare the result with the matching line in SHA256SUMS. On Linux check that the selected archive is actually reported OK; missing files are skipped.
