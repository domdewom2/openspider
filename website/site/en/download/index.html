Platforms & requirements

macOS

Desktop: macOS 13 or later, Apple Silicon (arm64) or Intel (x86_64).

Windows

Desktop: Windows 10 version 1809 or later, or Windows 11, x64. Requires the WebView2 Evergreen Runtime.

Linux

Core, CLI and MCP over STDIO: Linux x86_64 with glibc. Linux desktop and Linux installation packages are not supported.

Documented hardware requirements: at least 4 GB RAM; 8 GB or more and an SSD are recommended. Resource needs depend on the crawl and rendering.

Build the CLI from source

For developers: building the CLI requires the Rust toolchain with Cargo; cloning requires Git. See the repository for further instructions.

git clone https://github.com/domdewom2/openspider.git
cd openspider
cargo build --release -p os-cli
