Frequently asked questions

Is OpenSpider open source?

Yes. The source code is published under Apache-2.0 and is available on GitHub. The name and logo are excluded from this licence.

Where is my crawl data stored?

OpenSpider runs locally. Each crawl is saved as a SQLite file on your computer. Crawling contacts the websites you choose. Optional external integrations connect to their respective providers. Integrated AI services are planned and would also connect to their respective providers.

Do I need an account?

OpenSpider remains usable without an account. Optional external services are designed to use your own credentials or API keys.

Which platforms are supported?

The desktop app targets macOS and Windows. Linux x86_64 is supported for the core and CLI; a Linux desktop app is deliberately out of scope. See the download page for CLI guidance.

What does MCP mean?

The Model Context Protocol connects an AI agent to OpenSpider. For example, it can query issues and URL details from saved crawls. Only read tools are enabled by default.

Can I download the beta yet?

The public beta is in preparation. No beta download is enabled on this website yet. Releases will be available on GitHub Releases.

Does this website use cookies or trackers?

This static website uses no cookies, trackers, external fonts or embedded services. Information about server-side processing is available in the privacy notice.
