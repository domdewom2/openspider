OpenSpider · Beta

Try OpenSpider 1.0

The OpenSpider 1.0 beta is open to SEO freelancers, in-house teams and agencies. It is free, and the source code is on GitHub under the Apache 2.0 licence. Try the crawler on your own websites and tell us what works and what does not.

Installers on GitHub ↗Send feedback

Download and install

All installers are on the GitHub releases page ↗. The latest version is at the top. Under “Assets”, pick the file for your system:

  • macOS 13 or later: the universal DMG (file name ends in _universal.dmg) runs on Apple silicon and Intel. Open the DMG and drag OpenSpider to the Applications folder.
  • Windows 10 (1809 or later) or 11, x64: the setup EXE (_x64-setup.exe) installs for your user account without administrator rights. The MSI package (.msi) installs for all accounts on the computer and requires administrator rights. Windows on ARM uses the x64 installer under emulation.
  • Linux: core and command line only, as an archive (_linux-x86_64.tar.gz); no desktop app.

The download page explains how to check the files against SHA256SUMS.

First launch

macOS: the app is signed and notarized by Apple. When you open it for the first time, macOS asks once whether you want to open an app downloaded from the internet. Confirm if the source shown is your download from GitHub.

Windows: the installers are signed. Because the signing certificate is new, Microsoft Defender SmartScreen may still warn at first. Click “More info”, check the publisher shown and choose “Run anyway”. See the user guide for details.

Before you start

Beta software: back up important crawls before you update the app. File → “Save crawl as…” creates a copy of the crawl file.

During the beta, OpenSpider updates itself through its built-in update function: at startup the app checks for a new beta at most once a day and installs it only after you confirm. To check manually, use Help → “Check for updates”. You do not need to download new versions yourself.

Four test tasks

These four workflows help us most. Feel free to try anything else as well.

  1. Crawl your own website, ideally one with 10,000 URLs or more.
  2. Pause the running crawl and resume it.
  3. Export results, for example a table or a report.
  4. Quit the app, start it again and reopen the crawl (File → “Recently opened”).

Update privacy during the beta

Betas are normal GitHub releases until 1.0, with latest.json and latest-beta.json. There is no UI channel selector. Automatic checks send only version, operating system and architecture; no user identifier or crawl data, and no telemetry. GitHub sees the IP address required for the connection. Checks can be disabled in Settings → Updates or with OPENSPIDER_DISABLE_UPDATE_CHECK=1. The CLI and scheduled runs never check automatically. See update behavior and privacy. The privacy policy explains what happens to the information you enter in the form.
