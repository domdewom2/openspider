Agency beta

Join the agency beta

The beta is being prepared for three to five SEO agencies. Participation is coordinated by the project owner; no registration form is active yet. This page remains until release 1.0 and will be removed by M3-REL.

  1. Arrange participation with the project owner once invitations open.
  2. Use the approved GitHub release and your platform’s installer. Follow the download and checksum instructions and the user guide.
  3. Plan 60–90 minutes for installation, a small and a large crawl, JavaScript rendering, exports, comparison, scheduling, CLI and MCP. Use at least two real projects per agency, including one with at least 50,000 URLs.
  4. For round two, update from beta.1 to beta.2 through the app and report whether it succeeded. Back up important crawls first.

Update privacy during the beta

Betas are normal GitHub releases until 1.0, with latest.json and latest-beta.json. There is no UI channel selector. Automatic checks send only version, operating system and architecture; no user identifier or crawl data, and no telemetry. GitHub sees the IP address required for the connection. Checks can be disabled in Settings → Updates or with OPENSPIDER_DISABLE_UPDATE_CHECK=1. The CLI and scheduled runs never check automatically. See update behavior and privacy.
