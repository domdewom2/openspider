Weitere Dateien

Die Schaltflächen oben laden versionslose Kopien (OpenSpider-macOS.dmg, OpenSpider-Windows-Setup.exe), bytegleich mit den versionierten Dateien desselben Releases. Jedes Release enthält außerdem folgende Dateien; VERSION durch die Version ersetzen (zum Beispiel 1.0.0-beta.3):

  • macOS 13+ · Universal-DMG: OpenSpider_VERSION_universal.dmg
  • Windows x64 · Setup pro Benutzer (NSIS): OpenSpider_VERSION_x64-setup.exe
  • Windows x64 · MSI pro Rechner für Softwareverteilung: OpenSpider_<build-version>_x64_<language>.msi (exakten Namen aus dem Release übernehmen; MSI kann eine numerische Produktversion verwenden)
  • Kommandozeile: openspider_VERSION_darwin-universal.tar.gz (macOS), openspider_VERSION_windows-x86_64.zip (Windows), openspider_VERSION_linux-x86_64.tar.gz (Linux x86_64, glibc)
  • Prüfsummen: SHA256SUMS. Nur für automatische Updates der App: latest.json, latest-beta.json, *.app.tar.gz und *.sig.

URL-Muster: https://github.com/wojcikdominik/openspider/releases/download/vVERSION/DATEINAME

Windows on ARM verwendet den x64-Installer unter Emulation, keinen nativen ARM-Build. Linux unterstützt nur Kern und CLI. Linux-Desktop, .deb/.rpm und arm64-Releases sind nicht unterstützt.

SHA-256 prüfen

SHA256SUMS liegt im selben GitHub-Release und enthält die Prüfsummen aller Release-Dateien, auch der versionslosen Kopien. Prüfsummendatei und Installer/Archiv aus demselben Release laden; Dateinamen und vollständigen Hash vergleichen. Bei Abweichung nicht installieren. Prüfsummen prüfen die Integrität und ersetzen keine Signaturprüfung.

# macOS
shasum -a 256 OpenSpider-macOS.dmg
# Linux (place the downloaded archive and SHA256SUMS together)
sha256sum --ignore-missing -c SHA256SUMS
# Windows PowerShell
Get-FileHash .\OpenSpider-Windows-Setup.exe -Algorithm SHA256

Unter macOS und Windows das Ergebnis mit der passenden Zeile in SHA256SUMS vergleichen. Unter Linux prüfen, dass das gewählte Archiv tatsächlich als OK ausgegeben wird; fehlende Dateien werden übersprungen.

Docker (Server)

Für eigene Server gibt es ein Container-Image für Linux x86_64 mit CLI, Exporten, geplanten Läufen und MCP über STDIO, ohne Weboberfläche: Ergebnisse sind Dateien und Crawl-Dateien für die Desktop-App. Die Veröffentlichung unter ghcr.io/wojcikdominik/openspider ist vorbereitet; bis zur Freigabe das Image selbst aus dem Repository bauen. Ein fertiges Image auf ghcr.io folgt. Selbstbau, Ordner und Beispiele für Crawl, Vergleich, cron und MCP stehen im Handbuch.

Paketmanager: vorbereitet

Ein eigener Homebrew-Tap für macOS ist vorbereitet, aber noch nicht veröffentlicht; bis dahin die Release-Dateien verwenden. winget folgt mit Version 1.0. Stille Installation, SmartScreen, Gatekeeper und Deinstallation stehen im Handbuch.
