Windows on ARM verwendet den x64-Installer unter Emulation, keinen nativen ARM-Build. Linux unterstützt nur Kern und CLI. Linux-Desktop, .deb/.rpm und arm64-Releases sind nicht unterstützt.

MSI wird ebenfalls für Windows x64 gebaut. Der MSI-Dateiname enthält einen Sprachsuffix und folgt dem unten gezeigten Muster. Den exakten Dateinamen aus dem Release in das MSI-URL-Muster einsetzen; nicht vom NSIS-Namen ableiten. MSI verwendet eine numerische Produktversion (Beta-/RC-Abbildung), der Release-Tag dagegen SemVer.

OpenSpider_<build-version>_x64_<language>.msi

MSI-URL-Muster (gesamten Asset-Namen ersetzen): https://github.com/domdewom2/openspider/releases/download/vVERSION/MSI_ASSET_NAME.msi

SHA-256 prüfen

Das Release stellt SHA256SUMS im selben GitHub-Release bereit. Die Datei enthält die Prüfsummen der gesammelten Release-Assets. Prüfsummendatei und Installer/Archiv aus demselben freigegebenen Release laden; Dateinamen und vollständigen Hash vergleichen. Bei Abweichung nicht installieren. Prüfsummen prüfen die Integrität und ersetzen keine Signaturprüfung.

SHA256SUMS · URL-Muster: https://github.com/domdewom2/openspider/releases/download/vVERSION/SHA256SUMS

# macOS
shasum -a 256 OpenSpider_VERSION_aarch64.dmg
# Linux (place the downloaded archive and SHA256SUMS together)
sha256sum --ignore-missing -c SHA256SUMS
# Windows PowerShell
Get-FileHash .\OpenSpider_VERSION_x64-setup.exe -Algorithm SHA256

Unter macOS und Windows das Ergebnis mit der passenden Zeile in SHA256SUMS vergleichen. Unter Linux prüfen, dass das gewählte Archiv tatsächlich als OK ausgegeben wird; fehlende Assets werden übersprungen.
