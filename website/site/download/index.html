Plattformen & Voraussetzungen

macOS

Desktop: macOS 13 oder neuer, Apple Silicon (arm64) oder Intel (x86_64).

Windows

Desktop: Windows 10 ab Version 1809 oder Windows 11, x64. WebView2-Evergreen-Runtime erforderlich.

Linux

Kern, CLI und MCP über STDIO: Linux x86_64 mit glibc. Linux-Desktop und Linux-Installationspakete werden nicht unterstützt.

Dokumentierte Hardware-Voraussetzungen: mindestens 4 GB RAM; 8 GB oder mehr und eine SSD werden empfohlen. Der Bedarf hängt von Crawl und Rendering ab.

CLI aus dem Quellcode

Für Entwickler: Der CLI-Build benötigt die Rust-Toolchain mit Cargo; zum Klonen wird Git benötigt. Weitere Hinweise stehen im Repository.

git clone https://github.com/domdewom2/openspider.git
cd openspider
cargo build --release -p os-cli
