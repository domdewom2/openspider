Häufige Fragen

Ist OpenSpider Open Source?

Ja. Der Quellcode ist unter Apache-2.0 veröffentlicht und auf GitHub zugänglich. Name und Logo sind von dieser Lizenz ausgenommen.

Wo liegen meine Crawl-Daten?

OpenSpider läuft lokal. Jeder Crawl wird als SQLite-Datei auf deinem Rechner gespeichert. Beim Crawlen werden die von dir gewählten Websites kontaktiert. Optionale externe Integrationen und KI-Dienste stellen Verbindungen zum jeweiligen Anbieter her.

Brauche ich ein Konto?

OpenSpider bleibt ohne Konto nutzbar. Für optionale externe Dienste sind eigene Zugangsdaten beziehungsweise API-Schlüssel vorgesehen.

Welche Plattformen werden unterstützt?

Die Desktop-App zielt auf macOS und Windows. Linux x86_64 wird für Kern und CLI unterstützt; eine Linux-Desktop-App und Linux-Pakete werden nicht unterstützt.

Was bedeutet MCP?

Das Model Context Protocol verbindet einen KI-Agenten mit OpenSpider. Er kann damit beispielsweise Issues und URL-Details aus gespeicherten Crawls abfragen. Standardmäßig sind nur lesende Werkzeuge freigegeben.

Kann ich die Beta schon herunterladen?

Die öffentliche Beta ist in Vorbereitung. Auf dieser Website ist noch kein Beta-Download freigeschaltet. Veröffentlichungen werden auf GitHub Releases bereitgestellt.

Setzt diese Website Cookies oder Tracker ein?

Diese statische Website verwendet keine Cookies, Tracker, externen Schriftarten oder eingebetteten Dienste. Hinweise zur serverseitigen Verarbeitung ergänzt der Betreiber in der Datenschutzerklärung.
