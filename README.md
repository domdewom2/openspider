# OpenSpider

Open-source SEO crawler for macOS (Apple Silicon & Intel) and Windows. Rust core, Tauri desktop app.

Goal: a fast, memory-efficient website crawler and technical SEO auditor with feature parity to the leading commercial desktop crawlers – and beyond.

> Status: early development. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) and [docs/spec](docs/spec).
