# H1: Non-sequential

Typ: Warning (T-W2) · Priorität: Low (P-L1)

## Deutsch

**Was bedeutet das?** Vor der ersten H1 steht eine Überschrift einer anderen Ebene.

**Warum ist es relevant?** Die Hauptüberschrift sollte den Seiteninhalt klar und in sinnvoller Reihenfolge vermitteln.

**Wie beheben?** Setze die Hauptüberschrift vor untergeordnete Überschriften und prüfe die Gliederung der Seitenvorlage.

## English

**What does it mean?** Another heading level precedes the first H1.

**Why does it matter?** The main heading should clearly describe the page content in a meaningful order.

**How to fix** Place the main heading before subordinate headings and review the page template outline.
