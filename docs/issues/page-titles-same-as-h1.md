# Page Titles: Same as H1

Typ: Opportunity (T-O1) · Priorität: Low (P-L1)

## Deutsch

**Was bedeutet das?** Der erste Titel und die erste H1 enthalten denselben Text.

**Warum ist es relevant?** Gleicher Text kann sinnvoll sein; Titel und Hauptüberschrift werden jedoch in verschiedenen Kontexten angezeigt.

**Wie beheben?** Prüfe die betroffenen Elemente im Seitenkontext und passe das Template bei Bedarf an.

## English

**What does it mean?** The first title and first H1 have identical text.

**Why does it matter?** Matching text can be intentional, but the title and main heading serve different presentation contexts.

**How to fix** Review the affected elements in context and adjust the template when appropriate.
