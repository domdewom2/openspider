# Accessibility: aria-roles

Typ: Warning (T-W2) · Priorität: High (P-H2)

## Deutsch

**Was bedeutet das?** Die automatische Barrierefreiheitsprüfung meldet: ungültiger role-Wert.

**Warum ist es relevant?** Die betroffenen Elemente können die Bedienung mit Hilfstechnologien erschweren. Automatische Prüfungen ersetzen keine manuelle Prüfung.

**Wie beheben?** Prüfen Sie die markierten Elemente und die verlinkte Regelbeschreibung. Korrigieren Sie die Ursache und testen Sie erneut mit Tastatur und Hilfstechnologien.

## English

**What does it mean?** The automated accessibility check found this problem: ARIA role is invalid.

**Why does it matter?** These elements may make the page harder to use with assistive technology. Automated checks do not replace manual assessment.

**How to fix** Inspect the highlighted elements and the linked rule documentation. Correct the cause and retest with keyboard navigation and assistive technology.
