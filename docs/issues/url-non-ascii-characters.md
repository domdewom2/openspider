# URL: Non ASCII Characters

Typ: Warning (T-W2) · Priorität: Low (P-L1)

## Deutsch

**Was bedeutet das?** Die URL enthält Zeichen außerhalb des einfachen ASCII-Bereichs, etwa Umlaute oder Buchstaben mit Akzent.

**Warum ist es relevant?** Solche Zeichen werden kodiert übertragen, wodurch Adressen schwerer zu lesen, einzutippen und weiterzugeben sind. Manche Werkzeuge und ältere Systeme gehen uneinheitlich damit um.

**Wie beheben?** In neuen Adressen einfache Kleinbuchstaben, Ziffern und Bindestriche verwenden. Eine bestehende Adresse nur ändern, wenn der Nutzen klar ist, und die alte URL dann dauerhaft auf die neue weiterleiten.

## English

**What does it mean?** The URL contains characters outside the basic ASCII range, such as umlauts or accented letters.

**Why does it matter?** Such characters are sent in an encoded form, which makes addresses harder to read, type and share. Some tools and older systems handle them inconsistently.

**How to fix** Use plain lowercase letters, digits and hyphens in new addresses. Change an existing address only if the benefit is clear, and then redirect the old URL permanently to the new one.
