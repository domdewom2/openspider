# Pagination: Multiple Pagination URLs

Typ: Issue (T-I3) · Priorität: Low (P-L1)

## Deutsch

**Was bedeutet das?** Die Seite enthält mehr als eine next-Angabe oder mehr als eine prev-Angabe.

**Warum ist es relevant?** Mehrere Angaben derselben Richtung sind mehrdeutig, auch wenn sie derzeit auf dieselbe Adresse zeigen.

**Wie beheben?** Behalte je Richtung höchstens eine Angabe und gleiche HTML-Link-Elemente mit den HTTP-Link-Headern ab.

## English

**What does it mean?** This page contains more than one next annotation or more than one prev annotation.

**Why does it matter?** Multiple annotations for one direction are ambiguous, even when they currently point to the same address.

**How to fix** Keep at most one annotation per direction and reconcile HTML link elements with HTTP Link headers.
