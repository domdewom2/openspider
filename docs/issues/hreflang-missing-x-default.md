# Hreflang: Missing X-Default

Typ: Warning (T-W3) · Priorität: Low (P-L2)

## Deutsch

**Was bedeutet das?** Der Annotationssatz enthält keinen x-default-Eintrag.

**Warum ist es relevant?** Für Nutzer ohne passende Sprache ist kein ausdrückliches Ausweichziel zugeordnet.

**Wie beheben?** Ergänze bei Bedarf x-default für eine Sprachauswahl oder geeignete Standardseite.

## English

**What does it mean?** The annotation set has no x-default entry.

**Why does it matter?** Users without a matching language have no explicitly assigned fallback.

**How to fix** If a fallback is useful, add x-default pointing to a suitable selector or default page.
