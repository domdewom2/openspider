# Hreflang: Non-200 Hreflang URLs

Typ: Issue (T-I1) · Priorität: High (P-H2)

## Deutsch

**Was bedeutet das?** Eine in den hreflang-Angaben der Seite genannte Sprachalternative antwortet nicht mit Status 200.

**Warum ist es relevant?** Suchmaschinen können eine fehlende, weitergeleitete oder defekte Sprachversion nicht nutzen, sodass Suchenden unter Umständen die falsche Sprachfassung angezeigt wird.

**Wie beheben?** Die Angabe so korrigieren, dass sie die endgültige Adresse der Sprachversion nennt, oder die Zielseite reparieren, damit sie mit Status 200 antwortet. Einträge für nicht mehr vorhandene Versionen entfernen.

## English

**What does it mean?** A language alternative named in the hreflang annotations of the page does not answer with status 200.

**Why does it matter?** Search engines cannot use a language version that is missing, redirected or broken, so the wrong language version may be shown to searchers.

**How to fix** Correct the annotation so that it names the final address of the language version, or repair the target page so that it answers with status 200. Remove entries for versions that no longer exist.
