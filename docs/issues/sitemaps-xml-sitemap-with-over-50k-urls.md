# Sitemaps: XML Sitemap With Over 50k URLs

Typ: Issue (T-I2) · Priorität: High (P-H1)

## Deutsch

**Was bedeutet das?** Die XML-Sitemap oder der Sitemap-Index enthält mehr als 50.000 Einträge.

**Warum ist es relevant?** Suchmaschinen können Dateien oberhalb dieser Protokollgrenze verwerfen.

**Wie beheben?** Teile die Datei in Sitemaps beziehungsweise Indizes mit höchstens 50.000 Einträgen auf.

## English

**What does it mean?** The XML sitemap or sitemap index contains more than 50,000 entries.

**Why does it matter?** Search engines may reject files exceeding this protocol limit.

**How to fix** Split the file into sitemaps or indexes containing at most 50,000 entries each.
