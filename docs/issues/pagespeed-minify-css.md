# PageSpeed: Minify CSS

Typ: Opportunity (T-O2) · Priorität: Medium (P-M1)

## Deutsch

**Was bedeutet das?** CSS-Dateien enthalten Leerraum und Kommentare, die sich ohne Funktionsverlust entfernen lassen.

**Warum ist es relevant?** Unverkleinerte Stylesheets übertragen unnötige Bytes vor dem ersten Rendern.

**Wie beheben?** Verkleinere CSS im Build-Prozess (Minifizierung) und liefere es komprimiert aus.

## English

**What does it mean?** CSS files contain whitespace and comments that can be removed without changing behaviour.

**Why does it matter?** Unminified stylesheets transfer unnecessary bytes before the first render.

**How to fix** Minify CSS in the build process and serve it compressed.
