# Response Codes: External Server Error (5XX)

Typ: Warning (T-W3) · Priorität: Low (P-L2)

## Deutsch

**Was bedeutet das?** Eine verlinkte externe URL antwortet mit einem Server-Fehler im Bereich 5xx.

**Warum ist es relevant?** Die Zielwebsite liefert die Seite derzeit nicht aus, Besucher sehen nach dem Klick einen Fehler. Das Problem kann vorübergehend oder dauerhaft sein.

**Wie beheben?** Später erneut crawlen und prüfen, ob der Fehler verschwindet. Bleibt er bestehen, den Link durch eine andere Quelle ersetzen oder entfernen.

## English

**What does it mean?** A linked external URL answers with a server error status in the 5xx range.

**Why does it matter?** The target site currently fails to deliver the page, so visitors who follow the link see an error. The problem may be temporary or permanent.

**How to fix** Recrawl later to see whether the error disappears. If it persists, replace the link with another source or remove it.
