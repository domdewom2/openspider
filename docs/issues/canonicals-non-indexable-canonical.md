# Canonicals: Non-Indexable Canonical

Typ: Issue (T-I3) · Priorität: High (P-H2)

Befüllt erst nach der Crawl-Analyse.

## Deutsch

**Was bedeutet das?** Die kanonische Adresse der Seite zeigt auf eine nicht indexierbare URL, etwa mit Fehlerstatus, Weiterleitung oder noindex-Anweisung.

**Warum ist es relevant?** Ein Canonical-Hinweis auf ein unbrauchbares Ziel läuft ins Leere: Suchmaschinen ignorieren ihn, und die Seite kann als Duplikat gelten oder aus dem Index fallen.

**Wie beheben?** Das Canonical-Element auf eine Adresse setzen, die mit Status 200 antwortet, nicht gesperrt ist und indexiert werden kann. Wurde das Ziel verschoben, die Canonical-Angabe auf den neuen Ort ändern.

## English

**What does it mean?** The canonical address of the page points to a URL that cannot be indexed, for example one with an error status, a redirect or a noindex directive.

**Why does it matter?** A canonical hint to an unusable target runs into the void: search engines ignore it, and the page may be treated as a duplicate or fall out of the index.

**How to fix** Point the canonical element to an address that answers with status 200, is not blocked and can be indexed. If the target was moved, update the canonical element to the new location.
