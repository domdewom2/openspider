# PageSpeed: Duplicated JavaScript

Typ: Opportunity (T-O2) · Priorität: Medium (P-M1)

## Deutsch

**Was bedeutet das?** Dieselben Module oder Bibliotheken stecken mehrfach in den ausgelieferten Skripten.

**Warum ist es relevant?** Doppelter Code wird mehrfach geladen und ausgeführt.

**Wie beheben?** Prüfe die Bundles auf doppelte Abhängigkeiten und teile gemeinsamen Code in ein einziges Modul aus.

## English

**What does it mean?** The same modules or libraries are contained several times in the delivered scripts.

**Why does it matter?** Duplicate code is downloaded and executed more than once.

**How to fix** Check the bundles for duplicate dependencies and move shared code into a single module.
