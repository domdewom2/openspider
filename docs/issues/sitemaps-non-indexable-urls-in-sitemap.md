# Sitemaps: Non-Indexable URLs In Sitemap

Typ: Issue (T-I3) · Priorität: Medium (P-M2)

Befüllt erst nach der Crawl-Analyse.

## Deutsch

**Was bedeutet das?** Die Sitemap führt eine URL auf, die nicht indexiert werden kann, etwa weil sie weiterleitet, einen Fehler liefert oder eine noindex-Anweisung trägt.

**Warum ist es relevant?** Sitemaps sollten nur Adressen nennen, die im Index stehen sollen. Widersprüchliche Angaben verschwenden Crawl-Kapazität und mindern das Vertrauen in die Sitemap.

**Wie beheben?** Die betroffenen Adressen aus der Sitemap entfernen oder indexierbar machen, falls sie gefunden werden sollen. Die Sitemap nur aus der Liste der indexierbaren Seiten erzeugen.

## English

**What does it mean?** The sitemap lists a URL that cannot be indexed, for example one that redirects, returns an error or carries a noindex directive.

**Why does it matter?** Sitemaps should name only addresses that you want in the index. Contradicting information wastes crawl capacity and reduces the trust in the sitemap.

**How to fix** Remove the affected addresses from the sitemap or make them indexable if they should be found. Generate the sitemap from the list of indexable pages only.
