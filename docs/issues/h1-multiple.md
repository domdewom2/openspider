# H1: Multiple

Typ: Warning (T-W2) · Priorität: Medium (P-M1)

## Deutsch

**Was bedeutet das?** Die Seite enthält mehr als eine Überschrift erster Ebene.

**Warum ist es relevant?** Mehrere Hauptüberschriften verwischen das Thema der Seite. Hilfstechniken und Suchmaschinen können schwerer erkennen, worum es auf der Seite im Kern geht.

**Wie beheben?** Eine einzige h1 für das Hauptthema behalten und die übrigen Überschriften zu h2 oder tieferen Ebenen machen. Vorlagen prüfen, die Überschriften einfügen, etwa in Logos oder Widgets.

## English

**What does it mean?** The page contains more than one first-level heading.

**Why does it matter?** Several main headings blur the topic of the page. Assistive tools and search engines may find it harder to determine what the page is mainly about.

**How to fix** Keep a single h1 for the main topic and turn the other headings into h2 or lower levels. Check templates that add headings, for example in logos or widgets.
