# Response Codes: External Client Error (4XX)

Typ: Warning (T-W3) · Priorität: Low (P-L2)

## Deutsch

**Was bedeutet das?** Eine verlinkte externe URL antwortet mit einem Client-Fehler wie 404 (nicht gefunden).

**Warum ist es relevant?** Besucher, die dem Link folgen, landen auf einer Fehlerseite, was das Vertrauen in Ihre Inhalte mindert. Viele tote ausgehende Links können Seiten zudem veraltet wirken lassen.

**Wie beheben?** Den neuen Ort des Ziels oder eine vergleichbare Quelle suchen und den Link aktualisieren. Gibt es nichts Passendes, den Link entfernen und den umgebenden Satz anpassen.

## English

**What does it mean?** A linked external URL answers with a client error status such as 404 not found.

**Why does it matter?** Visitors who follow the link reach an error page, which weakens the trust in your content. Many dead outgoing links can also make pages look outdated.

**How to fix** Find the new location of the target or a comparable source and update the link. If nothing suitable exists, remove the link and adjust the sentence around it.
