# Images: Background Images

Typ: Opportunity (T-O1) · Priorität: Low (P-L1)

Befüllt erst nach der Crawl-Analyse.

## Deutsch

**Was bedeutet das?** Das Bild wird ausschließlich über CSS oder zur Laufzeit geladen.

**Warum ist es relevant?** Hintergrundbilder liefern keinen alternativen Text für diesen Inhalt.

**Wie beheben?** Prüfen, ob das Bild inhaltlich relevant ist. Relevante Bilder mit einem img-Element und passendem alt-Text einbinden.

## English

**What does it mean?** The image is loaded only through CSS or at runtime.

**Why does it matter?** Background images provide no alternative text for this content.

**How to fix** Check whether the image conveys information. Use an img element with suitable alternative text for informative images.
