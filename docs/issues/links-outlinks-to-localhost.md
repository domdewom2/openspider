# Links: Outlinks To Localhost

Typ: Issue (T-I1) · Priorität: High (P-H1)

## Deutsch

**Was bedeutet das?** Die Seite verweist auf einen Loopback-Host außerhalb der Startadresse des Crawls.

**Warum ist es relevant?** Diese Adressen führen zum Rechner des Besuchers statt zum öffentlichen Dienst.

**Wie beheben?** Ersetze Entwicklungsadressen durch die vorgesehenen Produktionsadressen.

## English

**What does it mean?** The page references a loopback host outside the crawl start authority.

**Why does it matter?** These addresses point to the visitor’s own computer rather than a public service.

**How to fix** Replace development URLs with the intended production URLs.
