# Meta Description: Below 70 Characters

Typ: Opportunity (T-O1) · Priorität: Low (P-L1)

## Deutsch

**Was bedeutet das?** Die Meta-Beschreibung ist kürzer als 70 Zeichen.

**Warum ist es relevant?** Eine sehr kurze Beschreibung nutzt den Platz in den Suchergebnissen nicht, um zu erklären, was die Seite bietet.

**Wie beheben?** Die Beschreibung auf mindestens 70 Zeichen erweitern. Den Inhalt der Seite zusammenfassen und einen Grund zum Klicken nennen.

## English

**What does it mean?** The meta description is shorter than 70 characters.

**Why does it matter?** A very short description does not use the space available in search results to explain what the page offers.

**How to fix** Expand the description to at least 70 characters. Summarise the content of the page and add a reason to click.
