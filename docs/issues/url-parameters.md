# URL: Parameters

Typ: Warning (T-W2) · Priorität: Low (P-L1)

## Deutsch

**Was bedeutet das?** Die URL enthält Abfrageparameter hinter einem Fragezeichen.

**Warum ist es relevant?** Parameter erzeugen oft viele Adressen für denselben Inhalt, etwa durch Sortierung, Filter oder Sitzungsdaten. Das verwässert Signale und verbraucht Crawl-Kapazität.

**Wie beheben?** Prüfen, welche Parameter den Inhalt wirklich ändern. Die übrigen aus internen Links entfernen oder die Canonical-Angabe auf die saubere Adresse setzen. Nur Parameter behalten, die tatsächlich gebraucht werden.

## English

**What does it mean?** The URL contains query parameters after a question mark.

**Why does it matter?** Parameters often create many addresses for the same content, for example through sorting, filters or session data. This dilutes signals and wastes crawl capacity.

**How to fix** Check which parameters really change the content. For the others, remove them from internal links or point the canonical element to the clean address. Keep only the parameters that are needed.
