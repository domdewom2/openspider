# Canonicals: Multiple Conflicting

Typ: Issue (T-I3) · Priorität: High (P-H2)

## Deutsch

**Was bedeutet das?** Die Seite nennt mehrere kanonische Adressen, die voneinander abweichen.

**Warum ist es relevant?** Widersprüchliche Hinweise lassen sich nicht alle befolgen, daher ignorieren Suchmaschinen sie wahrscheinlich und wählen die bevorzugte Fassung selbst, womöglich eine ungewollte Adresse.

**Wie beheben?** Sich auf eine bevorzugte Adresse festlegen und die übrigen Canonical-Einträge entfernen. Sowohl den HTML-Head als auch die HTTP-Header und Plugins prüfen, die Canonical-Elemente einfügen.

## English

**What does it mean?** The page names several canonical addresses that differ from each other.

**Why does it matter?** Contradicting hints cannot all be followed, so search engines will probably ignore them and choose the preferred version themselves, which may be an address you did not intend.

**How to fix** Decide on one preferred address and remove the other canonical entries. Look at the HTML head as well as the HTTP headers, and at plugins that insert canonical elements.
