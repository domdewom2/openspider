# Hreflang: Missing Return Links

Typ: Issue (T-I3) · Priorität: High (P-H2)

## Deutsch

**Was bedeutet das?** Eine in den hreflang-Angaben genannte Sprachalternative verweist nicht zu dieser Seite zurück.

**Warum ist es relevant?** Hreflang funktioniert nur, wenn beide Seiten sich gegenseitig bestätigen. Ohne Rückverweis ignorieren Suchmaschinen die Angabe unter Umständen und zeigen die falsche Sprachfassung.

**Wie beheben?** Auf der anderen Sprachseite die passende hreflang-Angabe ergänzen, sodass jede Fassung alle anderen und sich selbst aufführt. Die Angaben aus einer zentralen Liste erzeugen, damit sie konsistent bleiben.

## English

**What does it mean?** A language alternative named in the hreflang annotations does not link back to this page.

**Why does it matter?** Hreflang works only if both pages confirm each other. Without the return link, search engines may ignore the annotation and show the wrong language version.

**How to fix** Add the matching hreflang annotation on the other language page so that each version lists all others, including itself. Generate the annotations from one central list to keep them consistent.
