# Meta Description: Missing

Typ: Opportunity (T-O2) · Priorität: Low (P-L1)

## Deutsch

**Was bedeutet das?** Die Seite hat keine Meta-Beschreibung, oder die Beschreibung ist leer.

**Warum ist es relevant?** Ohne Beschreibung bauen Suchmaschinen den Textauszug aus dem Seitentext. Das funktioniert, aber Sie haben weniger Einfluss darauf, wie die Seite Suchenden präsentiert wird.

**Wie beheben?** Eine kurze, einmalige Zusammenfassung der Seite schreiben, die zum Klicken einlädt, und sie als Meta-Beschreibung im Head ergänzen. Dabei die empfohlene Länge einhalten.

## English

**What does it mean?** The page has no meta description, or the description is empty.

**Why does it matter?** Without a description, search engines build a snippet from the page text. That works, but you have less control over how the page is presented to searchers.

**How to fix** Write a short, unique summary of the page that invites a click and add it as a meta description in the head. Stay within the recommended length.
