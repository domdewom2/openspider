# Directives: NoImageIndex

Typ: Issue (T-W1) · Priorität: Low (P-L1)

Abweichung von der Herleitung: benchmark-parity: Spec-Benchmark TECH-061 verlangt Fehler als bewusste Hervorhebung der eingeschränkten Bildindexierung; Priorität bleibt niedrig.

## Deutsch

**Was bedeutet das?** Die Seite enthält die Robots-Direktive noimageindex.

**Warum ist es relevant?** Suchmaschinen sollen Bilder nicht über diese Seite indexieren. Die Seite selbst bleibt davon unabhängig indexierbar.

**Wie beheben?** Prüfe die gewünschte Bildsichtbarkeit und entferne die Direktive, wenn Bilder über diese Seite gefunden werden sollen.

## English

**What does it mean?** The page declares the noimageindex robots directive.

**Why does it matter?** Search engines are asked not to index images through this page. Page indexing is evaluated separately.

**How to fix** Review image visibility and remove the directive if images should be discovered through this page.
