# Pagination: Non-Indexable

Typ: Warning (T-W1) · Priorität: High (P-H1)

## Deutsch

**Was bedeutet das?** Die Seite enthält Paginierungsangaben, ist aber selbst nicht indexierbar.

**Warum ist es relevant?** Sperren, noindex oder eine abweichende kanonische URL können Folgeseiten von der Indexierung ausschließen.

**Wie beheben?** Prüfe den angezeigten Indexierbarkeitsgrund und korrigiere Sperren oder Canonicals, falls die Seite indexiert werden soll.

## English

**What does it mean?** This page contains pagination annotations but is itself classified as non-indexable.

**Why does it matter?** Blocking, noindex or a canonical pointing elsewhere can keep later pages of the series out of the index.

**How to fix** Review the stated indexability reason and adjust blocking directives or canonicals if this page should be indexed.
