# Search Console: No Search Analytics Data

Typ: Warning (T-W3) · Priorität: Low (P-L2)

## Deutsch

**Was bedeutet das?** Die gecrawlte HTML-Seite hatte im gewählten Zeitraum keine Impressionen in Search Analytics.

**Warum ist es relevant?** Entweder erscheint die Seite nicht in den Suchergebnissen, oder sie ist noch nicht indexiert.

**Wie beheben?** Prüfe die Indexierung mit der URL-Prüfung und ob die Seite Suchanfragen bedient, nach denen tatsächlich gesucht wird.

## English

**What does it mean?** The crawled HTML page received no impressions in Search Analytics for the selected period.

**Why does it matter?** Either the page is not shown in search results or it has not been indexed yet.

**How to fix** Check indexing with URL Inspection and review whether the page targets queries people search for.
