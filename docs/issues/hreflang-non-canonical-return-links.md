# Hreflang: Non-Canonical Return Links

Typ: Issue (T-I2) · Priorität: High (P-H2)

## Deutsch

**Was bedeutet das?** Ein Sprachziel nennt eine andere URL als maßgebliches Canonical.

**Warum ist es relevant?** Die annotierte Variante kann zugunsten der kanonischen Seite verworfen werden.

**Wie beheben?** Verwende die kanonische Zieladresse und prüfe deren Rückverweis.

## English

**What does it mean?** An alternate points to a page whose canonical identifies another URL.

**Why does it matter?** The annotated variant can be discarded in favour of its canonical.

**How to fix** Point the language annotation at the canonical page and check its return annotation.
