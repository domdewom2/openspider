# Meta Description: Over 155 Characters

Typ: Opportunity (T-O1) · Priorität: Low (P-L1)

## Deutsch

**Was bedeutet das?** Die Meta-Beschreibung ist länger als 155 Zeichen.

**Warum ist es relevant?** Suchmaschinen schneiden lange Beschreibungen ab, sodass die letzten Worte und ein möglicher Aufruf zum Handeln nicht angezeigt werden.

**Wie beheben?** Die Beschreibung auf höchstens 155 Zeichen kürzen und die Kernaussage an den Anfang stellen.

## English

**What does it mean?** The meta description is longer than 155 characters.

**Why does it matter?** Search engines cut long descriptions off, so the closing words and any call to action may not be displayed.

**How to fix** Shorten the description to at most 155 characters and put the key message first.
