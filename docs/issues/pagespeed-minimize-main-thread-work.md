# PageSpeed: Minimize Main-Thread Work

Typ: Opportunity (T-O2) · Priorität: Medium (P-M1)

## Deutsch

**Was bedeutet das?** Der Hauptthread ist beim Laden lange mit Stilberechnung, Layout, Rendern und Skripten beschäftigt.

**Warum ist es relevant?** Ein ausgelasteter Hauptthread reagiert verzögert auf Eingaben.

**Wie beheben?** Verringere Skriptarbeit, vereinfache Stile und Layout und verschiebe nicht dringende Aufgaben.

## English

**What does it mean?** The main thread is busy for a long time with style calculation, layout, painting and scripts during load.

**Why does it matter?** A busy main thread responds late to input.

**How to fix** Reduce script work, simplify styles and layout and postpone non-urgent tasks.
