# Page Titles: Multiple

Typ: Issue (T-I2) · Priorität: High (P-H2)

## Deutsch

**Was bedeutet das?** Die Seite enthält mehr als ein Title-Element.

**Warum ist es relevant?** Es kann nur ein Titel verwendet werden, Browser und Suchmaschinen müssen also wählen, und ihre Wahl entspricht womöglich nicht Ihrer Absicht.

**Wie beheben?** Die überzähligen Title-Elemente entfernen, sodass genau eines im Head bleibt. Plugins, Vorlagen und Skripte prüfen, die einen zweiten Titel einfügen könnten.

## English

**What does it mean?** The page contains more than one title element.

**Why does it matter?** Only one title can be used, so browsers and search engines have to choose, and the one they pick may not be the one you intended.

**How to fix** Remove the surplus title elements so that exactly one remains in the head. Check plugins, templates and scripts that may insert a second title.
