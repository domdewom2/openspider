# Links: Internal Nofollow Inlinks Only

Typ: Warning (T-W1) · Priorität: Low (P-L1)

Befüllt erst nach der Crawl-Analyse.

## Deutsch

**Was bedeutet das?** Alle bekannten internen Hyperlinks auf diese Seite sind nofollow.

**Warum ist es relevant?** Suchmaschinen stehen dadurch weniger nutzbare interne Wege zur Seite zur Verfügung.

**Wie beheben?** Ergänze einen passenden verfolgbaren Link, wenn die Seite auffindbar sein soll.

## English

**What does it mean?** Every known internal hyperlink to this page is nofollow.

**Why does it matter?** Search engines may have fewer usable internal paths to this page.

**How to fix** Add a relevant followed internal link if the page should be discoverable.
