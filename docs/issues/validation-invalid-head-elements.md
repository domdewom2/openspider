# Validation: Invalid HTML Elements In <head>

Typ: Warning (T-W2) · Priorität: High (P-H2)

## Deutsch

**Was bedeutet das?** Der Quelltext enthält unzulässige Elemente oder Text im Head.

**Warum ist es relevant?** Diese Inhalte können den Head vorzeitig beenden und nachfolgende Metadaten unwirksam machen.

**Wie beheben?** Verschiebe Seiteninhalte in den Body und belasse nur erlaubte Metadaten im Head. Prüfe auch noscript-Inhalte.

## English

**What does it mean?** The source contains elements or text that are not permitted in the head.

**Why does it matter?** These contents can end the head early and prevent later metadata from being used.

**How to fix** Move page content into the body and retain only permitted metadata in the head. Check noscript contents as well.
