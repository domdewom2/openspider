# Response Codes: Internal Redirection (3XX)

Typ: Warning (T-W2) · Priorität: Low (P-L1)

## Deutsch

**Was bedeutet das?** Die interne URL antwortet mit einer Weiterleitung auf eine andere Adresse, statt selbst Inhalt zu liefern.

**Warum ist es relevant?** Eine Weiterleitung ist normal, aber jeder interne Link auf eine weiterleitende Adresse kostet eine zusätzliche Anfrage und verzögert Besucher und Crawler geringfügig.

**Wie beheben?** Interne Links, Canonical-Angaben und Sitemap-Einträge direkt auf die endgültige Zieladresse setzen. Die Weiterleitung selbst bleibt für externe Links und Lesezeichen bestehen.

## English

**What does it mean?** The internal URL answers with a redirect to another address instead of delivering content itself.

**Why does it matter?** One redirect is normal, but every internal link that points to a redirecting address costs an extra request and slightly delays visitors and crawlers.

**How to fix** Update internal links, canonical elements and sitemap entries so that they point straight at the final target address. Keep the redirect itself in place for external links and bookmarks.
