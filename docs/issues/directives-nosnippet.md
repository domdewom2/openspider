# Directives: NoSnippet

Typ: Warning (T-W1) · Priorität: Low (P-L1)

## Deutsch

**Was bedeutet das?** Eine Robots-Angabe unterbindet Suchergebnis-Snippets.

**Warum ist es relevant?** Fehlende Vorschautexte können die Auswahl des Ergebnisses erschweren.

**Wie beheben?** Prüfe die beabsichtigte Darstellung und entferne nosnippet, falls Vorschauen erlaubt sein sollen.

## English

**What does it mean?** A robots directive disables search result snippets.

**Why does it matter?** Missing preview text can make the result harder to assess.

**How to fix** Review the intended presentation and remove nosnippet if previews should be allowed.
