# Search Console: Page Is Not Mobile Friendly

Typ: Issue (T-I3) · Priorität: High (P-H3)

## Deutsch

**Was bedeutet das?** Die URL-Prüfung von Google meldet für diese Seite eine nicht bestandene Prüfung der mobilen Nutzbarkeit.

**Warum ist es relevant?** Auf Smartphones ist die Seite schwer lesbar oder bedienbar, und Google bewertet zuerst die mobile Fassung.

**Wie beheben?** Prüfe die aufgeführten Probleme der mobilen Nutzbarkeit, korrigiere Layout, Schriftgröße und Tippflächen und prüfe die URL erneut.

## English

**What does it mean?** Google's URL Inspection reports a failed mobile usability check for this page.

**Why does it matter?** Visitors on phones may struggle to read or use the page, and Google evaluates the mobile version first.

**How to fix** Open the listed mobile usability issues, fix layout, font size and tap targets, then inspect the URL again.
