# Validation: Resource Over 2MB

Typ: Issue (T-I2) · Priorität: High (P-H2)

## Deutsch

**Was bedeutet das?** Die JavaScript- oder CSS-Ressource überschreitet die konfigurierte Größengrenze oder wurde beim Abruf abgeschnitten.

**Warum ist es relevant?** Eine nur teilweise verarbeitete Ressource kann die Darstellung und die Erkennung von Seiteninhalten beeinträchtigen.

**Wie beheben?** Verkleinere oder teile die Ressource, entferne ungenutzten Code und prüfe die konfigurierte Größengrenze sowie das Download-Limit.

## English

**What does it mean?** The JavaScript or CSS resource exceeds the configured size threshold or its download was truncated.

**Why does it matter?** A resource that is only partly processed can impair rendering and the recognition of page content.

**How to fix** Reduce or split the resource, remove unused code and check the configured size threshold and the download limit.
