# Pagination: Pagination URL Not In Anchor Tag

Typ: Issue (T-I3) · Priorität: High (P-H1)

## Deutsch

**Was bedeutet das?** Mindestens ein Paginierungsziel fehlt als normaler Ankerlink auf dieser Seite.

**Warum ist es relevant?** Link-Elemente ersetzen keine anklickbare Navigation; weitere Inhalte können dadurch schwerer erreichbar sein.

**Wie beheben?** Ergänze für jedes next- oder prev-Ziel einen passenden a-href-Link in der Seitennavigation.

## English

**What does it mean?** At least one pagination target has no ordinary anchor link on this page.

**Why does it matter?** Link elements do not replace clickable navigation, so visitors may have difficulty reaching further content.

**How to fix** Add an a-href link for every next or prev target in the navigation on the source page.
