# URL: GA Tracking Parameters

Typ: Warning (T-W2) · Priorität: Low (P-L1)

## Deutsch

**Was bedeutet das?** Die Query enthält einen Parameter mit dem Anfang utm_ oder dem Namen _ga oder _gl.

**Warum ist es relevant?** Tracking-Parameter können weitere URL-Varianten desselben Inhalts erzeugen und Crawl-Kapazität beanspruchen.

**Wie beheben?** Prüfe interne Links und entferne unnötige Tracking-Parameter. Nutze bei Bedarf URL-Umschreibungen für den Crawl, sofern diese Parameter den Inhalt nicht verändern.

## English

**What does it mean?** The query contains a parameter beginning with utm_ or named _ga or _gl.

**Why does it matter?** Tracking parameters can create additional URL variants for the same content and consume crawl capacity.

**How to fix** Review internal links and remove unnecessary tracking parameters. Use URL rewriting for a crawl when those parameters do not change the content.
