# PageSpeed: Font Display

Typ: Opportunity (T-O2) · Priorität: Low (P-L1)

## Deutsch

**Was bedeutet das?** Webfonts halten Text während des Ladens unsichtbar.

**Warum ist es relevant?** Unsichtbarer Text verzögert, ab wann Inhalte lesbar sind.

**Wie beheben?** Setze font-display: swap oder optional, damit sofort eine Ersatzschrift angezeigt wird.

## English

**What does it mean?** Web fonts keep text invisible while they load.

**Why does it matter?** Invisible text delays the moment content becomes readable.

**How to fix** Use font-display: swap or optional so a fallback font is shown immediately.
