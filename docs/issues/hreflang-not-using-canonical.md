# Hreflang: Not Using Canonical

Typ: Issue (T-I2) · Priorität: High (P-H2)

## Deutsch

**Was bedeutet das?** Die Seite ist kanonisiert und keine ihrer Annotationen verwendet ihre Canonical-URL.

**Warum ist es relevant?** Sprachangaben und Canonical zeigen auf verschiedene Seitenvarianten.

**Wie beheben?** Verwende die Canonical-URL im Sprachsatz und passe die Rückverweise an.

## English

**What does it mean?** The page is canonicalised and none of its annotations uses its canonical URL.

**Why does it matter?** Language signals and canonical signals identify different page variants.

**How to fix** Use the canonical URL in the annotation set and align the return annotations.
