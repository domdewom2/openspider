# Search Console: AMP URL Is Invalid

Typ: Issue (T-I3) · Priorität: Medium (P-M1)

## Deutsch

**Was bedeutet das?** Die URL-Prüfung meldet die AMP-Fassung dieser Seite als ungültig.

**Warum ist es relevant?** Eine ungültige AMP-Seite wird nicht als AMP ausgeliefert; die zugehörigen Suchfunktionen stehen ihr nicht zur Verfügung.

**Wie beheben?** Behebe die AMP-Validierungsfehler aus der Spalte AMP Issues und prüfe die URL erneut.

## English

**What does it mean?** URL Inspection reports the AMP version of this page as invalid.

**Why does it matter?** An invalid AMP page is not served as AMP, so the related search features are not available for it.

**How to fix** Correct the AMP validation errors listed in the AMP Issues column and inspect the URL again.
