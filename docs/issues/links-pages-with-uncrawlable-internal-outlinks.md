# Links: Pages With Uncrawlable Internal Outlinks

Typ: Warning (T-W2) · Priorität: High (P-H2)

## Deutsch

**Was bedeutet das?** Die Seite enthält gespeicherte interne Navigation ohne crawlbaren Hyperlink.

**Warum ist es relevant?** Suchmaschinen finden Ziele möglicherweise nicht, wenn die Navigation nur per Skript erfolgt.

**Wie beheben?** Verwende für Navigationslinks ein Ankerelement mit regulärem href.

## English

**What does it mean?** The page contains stored internal navigation that is not a crawlable hyperlink.

**Why does it matter?** Search engines may not discover destinations implemented only as scripted navigation.

**How to fix** Use an anchor element with a regular href for navigational links.
