# Search Console: User-Declared Canonical Not Selected

Typ: Warning (T-W3) · Priorität: Medium (P-M1)

## Deutsch

**Was bedeutet das?** Google hat eine andere kanonische URL gewählt als die, die die Seite angibt.

**Warum ist es relevant?** Google übergeht das angegebene Canonical; die Signale werden auf einer ungewollten URL zusammengeführt.

**Wie beheben?** Unterscheide doppelte Seiten klar oder richte Canonical-Tags, Weiterleitungen, interne Links und Sitemaps auf eine URL aus.

## English

**What does it mean?** Google chose a different canonical URL than the one the page declares.

**Why does it matter?** Google ignores the declared canonical, so signals are consolidated on a URL you did not intend.

**How to fix** Make duplicate pages clearly distinct, or align canonical tags, redirects, internal links and sitemaps on one URL.
