# Security: Form URL Insecure

Typ: Issue (T-I4) · Priorität: High (P-H3)

## Deutsch

**Was bedeutet das?** Ein Formular sendet an eine HTTP-Adresse.

**Warum ist es relevant?** Formulardaten können auf dem Übertragungsweg gelesen oder verändert werden.

**Wie beheben?** Das Formularziel auf HTTPS umstellen und die sichere Übertragung prüfen.

## English

**What does it mean?** A form on this page submits its data to an unencrypted HTTP address.

**Why does it matter?** Form data can be read or altered on the network path.

**How to fix** Change the form action to HTTPS and verify secure submission.
