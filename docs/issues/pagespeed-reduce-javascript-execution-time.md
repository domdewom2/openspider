# PageSpeed: Reduce JavaScript Execution Time

Typ: Opportunity (T-O2) · Priorität: Medium (P-M1)

## Deutsch

**Was bedeutet das?** Das Parsen, Kompilieren und Ausführen von JavaScript dauert lange.

**Warum ist es relevant?** Lange Skriptausführung blockiert den Hauptthread und verzögert Interaktionen.

**Wie beheben?** Reduziere und verschiebe Skriptarbeit, entferne teure Drittanbieter-Skripte und teile lange Aufgaben auf.

## English

**What does it mean?** Parsing, compiling and running JavaScript takes a long time.

**Why does it matter?** Long script execution blocks the main thread and delays interactions.

**How to fix** Reduce and defer script work, drop expensive third-party scripts and break up long tasks.
