# H1: Duplicate

Typ: Opportunity (T-O1) · Priorität: Low (P-L1)

## Deutsch

**Was bedeutet das?** Mehrere Seiten verwenden dieselbe Überschrift erster Ebene.

**Warum ist es relevant?** Gleiche Hauptüberschriften lassen Seiten so wirken, als behandelten sie dasselbe Thema, und machen das Navigieren über Überschriften weniger hilfreich.

**Wie beheben?** Jeder Seite eine Hauptüberschrift geben, die ihren eigenen Inhalt beschreibt. Seiten zusammenführen, die sich tatsächlich doppeln.

## English

**What does it mean?** Several pages use the same first-level heading.

**Why does it matter?** Identical main headings make pages appear to cover the same topic and make navigating by headings less useful.

**How to fix** Give each page a main heading that describes its own content. Merge pages that truly duplicate each other.
