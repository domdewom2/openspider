# Validation: HTML Document Over 2MB

Typ: Issue (T-I2) · Priorität: High (P-H2)

## Deutsch

**Was bedeutet das?** Das HTML-Dokument überschreitet die konfigurierte Größengrenze oder wurde beim Abruf abgeschnitten.

**Warum ist es relevant?** Suchmaschinen können den hinteren Teil großer Dokumente auslassen. Dort stehende Inhalte und Links gehen verloren.

**Wie beheben?** Verkleinere das Dokument, entferne unnötiges Inline-Markup oder teile die Inhalte auf. Prüfe die konfigurierte Größengrenze und das Download-Limit.

## English

**What does it mean?** The HTML document exceeds the configured size threshold or its download was truncated.

**Why does it matter?** Search engines may omit the end of large documents, losing content and links located there.

**How to fix** Reduce the document, remove unnecessary inline markup or split its contents. Check the configured size threshold and the download limit.
