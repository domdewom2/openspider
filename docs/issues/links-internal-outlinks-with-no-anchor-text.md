# Links: Internal Outlinks With No Anchor Text

Typ: Opportunity (T-O1) · Priorität: Low (P-L1)

## Deutsch

**Was bedeutet das?** Die Seite enthält interne Links ohne Ankertext, etwa einen Bildlink ohne Alternativtext oder einen leeren Link.

**Warum ist es relevant?** Der Ankertext sagt Besuchern und Suchmaschinen, was sie hinter einem Link erwartet. Leere Links nützen Screenreader-Nutzern nichts und geben Suchmaschinen keinen Zusammenhang.

**Wie beheben?** Jedem Link einen aussagekräftigen Text geben. Bei Bildlinks dem Bild einen sinnvollen Alternativtext mitgeben. Leere Links ohne Zweck entfernen.

## English

**What does it mean?** The page contains internal links without any anchor text, for example an image link without alternative text or an empty link.

**Why does it matter?** The anchor text tells visitors and search engines what to expect behind a link. Empty links are useless for screen reader users and give search engines no context.

**How to fix** Give each link a descriptive text. For image links, put a meaningful alt text on the image. Remove empty links that serve no purpose.
