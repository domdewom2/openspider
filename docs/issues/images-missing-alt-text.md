# Images: Missing Alt Text

Typ: Issue (T-I2) · Priorität: Low (P-L1)

## Deutsch

**Was bedeutet das?** Das Bild wird auf einer Seite mit vorhandenem, aber leerem alt-Attribut verwendet.

**Warum ist es relevant?** Nutzer von Screenreadern und Suchmaschinen erfahren nur aus dem Alternativtext, was ein Bild zeigt. Dekorative Bilder sind eine Ausnahme, informative Bilder brauchen eine Beschreibung.

**Wie beheben?** Eine kurze Beschreibung schreiben, was das Bild zeigt und wozu es dient, und sie ins alt-Attribut eintragen. Das alt-Attribut nur bei rein dekorativen Bildern leer lassen.

## English

**What does it mean?** The image is used on a page with an alt attribute that is present but empty.

**Why does it matter?** Screen reader users and search engines learn what an image shows only from its alternative text. Decorative images are an exception, informative images need a description.

**How to fix** Write a short description of what the image shows and why it is there, and put it into the alt attribute. Keep the alt attribute empty only for purely decorative images.
