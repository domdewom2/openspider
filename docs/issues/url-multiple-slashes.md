# URL: Multiple Slashes

Typ: Issue (T-I2) · Priorität: Low (P-L1)

## Deutsch

**Was bedeutet das?** Die URL enthält im Pfad zwei oder mehr Schrägstriche hintereinander.

**Warum ist es relevant?** Server können eine solche Adresse als andere Seite behandeln als die saubere, was zu doppelten Inhalten und Fehlern führt. Meist steckt ein Fehler beim Zusammensetzen der Links dahinter.

**Wie beheben?** Die Vorlage oder Link-Funktion suchen, die die Pfadteile verbindet, und den überzähligen Schrägstrich entfernen. Die fehlerhafte Adresse dauerhaft auf die saubere Fassung weiterleiten und interne Links korrigieren.

## English

**What does it mean?** The URL contains two or more slashes in a row inside its path.

**Why does it matter?** Servers may treat such an address as a different page than the clean one, which leads to duplicate content and errors. It usually stems from a mistake when links are assembled.

**How to fix** Find the template or link builder that joins the path parts and remove the surplus slash. Redirect the faulty address permanently to the clean version and correct internal links.
