# H1: Missing

Typ: Issue (T-I2) · Priorität: Medium (P-M1)

## Deutsch

**Was bedeutet das?** Die Seite hat keine Überschrift erster Ebene, oder die Überschrift ist leer.

**Warum ist es relevant?** Die Hauptüberschrift sagt Besuchern und Suchmaschinen, worum es auf der Seite geht. Ohne sie leiden Struktur und Barrierefreiheit der Seite.

**Wie beheben?** Eine klare h1-Überschrift ergänzen, die das Thema der Seite nennt und die wichtigsten Begriffe des Titels aufgreift. Überschriftenelemente zur Gliederung nutzen, nicht nur zur Gestaltung.

## English

**What does it mean?** The page has no first-level heading, or the heading is empty.

**Why does it matter?** The main heading tells visitors and search engines what the page is about. Without it, page structure and accessibility suffer.

**How to fix** Add one clear h1 heading that states the topic of the page and reflects the main wording of the title. Use heading elements for structure, not only for styling.
