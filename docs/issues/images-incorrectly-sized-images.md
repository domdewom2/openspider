# Images: Incorrectly Sized Images

Typ: Opportunity (T-O2) · Priorität: Low (P-L1)

Befüllt erst nach der Crawl-Analyse.

## Deutsch

**Was bedeutet das?** Mindestens eine sichtbare Bildeinbindung lädt mehr Pixel als für ihre Anzeige nötig.

**Warum ist es relevant?** Eine passend skalierte Bilddatei kann die übertragene Datenmenge verringern. Die Einsparung ist eine Schätzung anhand des Flächenverhältnisses.

**Wie beheben?** Bilder in passenden Abmessungen ausliefern und für verschiedene Anzeigegrößen srcset und sizes verwenden.

## English

**What does it mean?** At least one visible image instance loads more pixels than its display size requires.

**Why does it matter?** An appropriately sized image can reduce transferred bytes. Savings are estimated from the ratio of display area to image area.

**How to fix** Deliver appropriately sized images and use srcset and sizes for different display sizes.
