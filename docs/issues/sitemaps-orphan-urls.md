# Sitemaps: Orphan URLs

Typ: Issue (T-I3) · Priorität: Medium (P-M2)

Befüllt erst nach der Crawl-Analyse.

## Deutsch

**Was bedeutet das?** Die URL ist nicht über Links von der Startseite aus erreichbar. Sie ist nur aus einer Sitemap bekannt oder wurde nur über eine solche URL gefunden.

**Warum ist es relevant?** Seiten, die nur in einer Sitemap stehen, haben keine internen Linksignale. Besucher können nicht zu ihnen navigieren, und Suchmaschinen halten sie tendenziell für weniger wichtig.

**Wie beheben?** Die Seite von passenden Seiten der Website aus verlinken, etwa von Kategorie- oder Übersichtsseiten. Ist die Seite veraltet, sie aus der Sitemap nehmen und weiterleiten oder löschen.

## English

**What does it mean?** The URL cannot be reached by following links from the start page. It is known only from a sitemap or was found only through such a URL.

**Why does it matter?** Pages that exist only in a sitemap lack internal link signals. Visitors cannot navigate to them, and search engines tend to value them as less important.

**How to fix** Link the page from relevant pages of the site, for example from category or overview pages. If the page is obsolete, remove it from the sitemap and redirect or delete it.
