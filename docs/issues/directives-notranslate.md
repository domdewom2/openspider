# Directives: NoTranslate

Typ: Warning (T-W1) · Priorität: Low (P-L1)

## Deutsch

**Was bedeutet das?** Eine Meta- oder Header-Angabe fordert notranslate an.

**Warum ist es relevant?** Die Angabe kann Übersetzungsangebote im Suchergebnis unterdrücken.

**Wie beheben?** Prüfe, ob die Einschränkung weiterhin gewünscht ist, und entferne sie gegebenenfalls.

## English

**What does it mean?** A meta or header directive requests notranslate.

**Why does it matter?** This directive can suppress translation options in search results.

**How to fix** Check whether the restriction is still intended and remove it when appropriate.
