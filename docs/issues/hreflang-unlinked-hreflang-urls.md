# Hreflang: Unlinked Hreflang URLs

Typ: Issue (T-I2) · Priorität: Medium (P-M1)

Befüllt erst nach der Crawl-Analyse.

## Deutsch

**Was bedeutet das?** Ein Sprachziel hat keinen eingehenden Hyperlink von einer internen Seite.

**Warum ist es relevant?** Sprachangaben allein lassen Lücken bei Navigation und Auffindbarkeit.

**Wie beheben?** Verlinke das Ziel von passenden internen Seiten und prüfe die Zieladresse.

## English

**What does it mean?** An alternate has no incoming hyperlink from an internal page.

**Why does it matter?** Language annotations alone leave a gap in navigation and discovery.

**How to fix** Link the alternate from relevant internal pages and verify the annotation target.
