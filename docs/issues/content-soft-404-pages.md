# Content: Soft 404 Pages

Typ: Warning (T-W2) · Priorität: High (P-H1)

## Deutsch

**Was bedeutet das?** Eine Seite mit Status 200 enthält eine konfigurierte Fehlerphrase.

**Warum ist es relevant?** Ein Erfolgsstatus kann eine fehlende Seite verdecken. Die Textprüfung kann auch Artikel über Fehler treffen.

**Wie beheben?** Prüfe die gefundene Phrase. Liefere für entfernte Inhalte 404 oder 410 oder korrigiere den Seitentext.

## English

**What does it mean?** A page with status 200 contains a configured error phrase.

**Why does it matter?** A successful status may conceal a missing page. This phrase check can also match articles discussing errors.

**How to fix** Check the matched phrase. Return 404 or 410 for removed content, or correct the page text.
