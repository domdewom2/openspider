# Search Console: Indexable URL Not Indexed

Typ: Warning (T-W3) · Priorität: High (P-H1)

## Deutsch

**Was bedeutet das?** OpenSpider bewertet die URL als indexierbar, Google meldet sie aber als nicht bei Google.

**Warum ist es relevant?** Eine Seite, die für die Suche gedacht ist, aber im Index fehlt, bringt keinen organischen Traffic.

**Wie beheben?** Prüfe den Abdeckungsstatus, stärke interne Links und Inhalt und beantrage die Indexierung, sobald die Ursache behoben ist.

## English

**What does it mean?** OpenSpider rates the URL as indexable, but Google reports that it is not on Google.

**Why does it matter?** A page that is meant for search but missing from the index cannot bring organic traffic.

**How to fix** Check the coverage state, improve internal links and content quality, and request indexing once the cause is resolved.
