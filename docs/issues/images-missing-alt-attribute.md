# Images: Missing Alt Attribute

Typ: Issue (T-I2) · Priorität: Low (P-L1)

## Deutsch

**Was bedeutet das?** Das Bild wird auf einer Seite ganz ohne alt-Attribut verwendet.

**Warum ist es relevant?** Ohne alt-Attribut lesen Screenreader womöglich den Dateinamen vor, und Suchmaschinen erhalten keine Beschreibung des Bildes.

**Wie beheben?** Jedem Bildelement ein alt-Attribut geben. Informative Bilder in wenigen Worten beschreiben und bei rein dekorativen Bildern ein leeres alt-Attribut verwenden.

## English

**What does it mean?** The image is used on a page without any alt attribute.

**Why does it matter?** Without an alt attribute, screen readers may read out the file name instead, and search engines get no description of the image.

**How to fix** Add an alt attribute to every image element. Describe informative images in a few words and use an empty alt attribute for purely decorative ones.
