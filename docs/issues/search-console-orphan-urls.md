# Search Console: Orphan URLs

Typ: Issue (T-I3) · Priorität: Medium (P-M2)

## Deutsch

**Was bedeutet das?** Die Seite hat Search-Analytics-Daten, aber keine andere gecrawlte Seite verlinkt sie intern.

**Warum ist es relevant?** Seiten, die nur von außen erreichbar sind, erhalten keine internen Linksignale und geraten leicht aus dem Blick.

**Wie beheben?** Verlinke die Seite aus einem passenden Bereich der Website oder leite sie um bzw. entferne sie, wenn sie nicht mehr gebraucht wird.

## English

**What does it mean?** The page has Search Analytics data but no internal link from another crawled page points to it.

**Why does it matter?** Pages that are only reachable from outside receive no internal link signals and are easy to lose track of.

**How to fix** Link the page from a relevant section of the site, or redirect or remove it if it is no longer needed.
