# Canonicals: Unlinked

Typ: Warning (T-W1) · Priorität: Medium (P-M1)

Befüllt erst nach der Crawl-Analyse.

## Deutsch

**Was bedeutet das?** Das kanonische Ziel hat keinen Hyperlink von einer internen Seite.

**Warum ist es relevant?** Suchmaschinen erhalten ein Canonical-Signal, können das Ziel aber nicht über die normale interne Navigation erreichen.

**Wie beheben?** Das bevorzugte Ziel aus relevanten internen Seiten direkt verlinken und die Canonical-Auswahl prüfen.

## English

**What does it mean?** The canonical target has no hyperlink from an internal page.

**Why does it matter?** Search engines receive a canonical signal but cannot reach its target through normal internal navigation.

**How to fix** Link directly to the preferred target from relevant internal pages and review the canonical choice.
