# Canonicals: Canonical Is Relative

Typ: Warning (T-W2) · Priorität: Low (P-L1)

## Deutsch

**Was bedeutet das?** Mindestens eine Canonical-Angabe verwendet eine relative Adresse.

**Warum ist es relevant?** Die Zieladresse hängt von der Dokumentbasis ab; Änderungen an Basis oder Auslieferung können das Ziel verschieben.

**Wie beheben?** Eine vollständige HTTPS-Adresse für das beabsichtigte kanonische Ziel eintragen.

## English

**What does it mean?** At least one canonical annotation uses a relative address.

**Why does it matter?** Its destination depends on the document base; changes to that base or delivery can change the target.

**How to fix** Use the complete HTTPS address of the intended canonical target.
