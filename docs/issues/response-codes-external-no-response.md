# Response Codes: External No Response

Typ: Warning (T-W3) · Priorität: Low (P-L2)

## Deutsch

**Was bedeutet das?** Eine verlinkte externe URL hat nicht geantwortet, etwa wegen einer Zeitüberschreitung oder einer fehlgeschlagenen DNS-Auflösung.

**Warum ist es relevant?** Links auf nicht erreichbare Websites enttäuschen Besucher und lassen eine Seite ungepflegt wirken. Die Ursache liegt außerhalb der eigenen Website, ob der Link bleibt, entscheiden aber Sie.

**Wie beheben?** Den Link im Browser öffnen und prüfen, ob das Ziel nur kurz ausgefallen ist. Bleibt es unerreichbar, den Link entfernen oder durch eine funktionierende Quelle ersetzen.

## English

**What does it mean?** A linked external URL did not answer, for example because of a timeout or a failed DNS lookup.

**Why does it matter?** Links to unreachable sites frustrate visitors and make a page look neglected. The cause lies outside your site, but you decide whether the link stays.

**How to fix** Open the link in a browser to see whether the target is only down for a moment. If it stays unreachable, remove the link or replace it with a working source.
