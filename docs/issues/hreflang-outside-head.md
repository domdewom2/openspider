# Hreflang: Outside <head>

Typ: Issue (T-I1) · Priorität: High (P-H2)

## Deutsch

**Was bedeutet das?** Eine HTML-Sprachannotation steht außerhalb des geparsten head-Elements.

**Warum ist es relevant?** Suchmaschinen können Angaben außerhalb des Dokumentkopfs ignorieren.

**Wie beheben?** Verschiebe die Angabe in einen gültigen head und behebe Markup, das den Kopf vorzeitig beendet.

## English

**What does it mean?** An HTML language annotation is outside the parsed head element.

**Why does it matter?** Search engines may ignore annotations placed outside the document head.

**How to fix** Move the element into a valid head and fix markup that closes the head prematurely.
