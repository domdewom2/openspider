# Structured Data: Validation Errors

Typ: Issue (T-I2) · Priorität: High (P-H2)

## Deutsch

**Was bedeutet das?** Mindestens ein Element strukturierter Daten verwendet einen Typ, eine Eigenschaft oder einen Wert, der nicht zum schema.org-Vokabular passt.

**Warum ist es relevant?** Unbekannte Namen, Eigenschaften an unpassenden Typen und Werte der falschen Art können dazu führen, dass das Markup ignoriert oder falsch gedeutet wird.

**Wie beheben?** Öffnen Sie die Details der strukturierten Daten und korrigieren Sie jeden Befund am angegebenen Eigenschaftspfad. Prüfen Sie Schreibweise sowie Groß- und Kleinschreibung anhand der schema.org-Referenz.

## English

**What does it mean?** At least one structured data item uses a type, property or value that does not fit the schema.org vocabulary.

**Why does it matter?** Unknown names, properties on unsuitable types and values of the wrong kind can cause the markup to be ignored or misread.

**How to fix** Open the structured data details and correct each finding at the listed property path. Check spelling and case against the schema.org reference.
