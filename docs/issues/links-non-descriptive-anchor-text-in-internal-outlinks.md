# Links: Non-Descriptive Anchor Text In Internal Outlinks

Typ: Opportunity (T-O1) · Priorität: Low (P-L1)

## Deutsch

**Was bedeutet das?** Interne Links verwenden einen allgemeinen Ankertext aus der konfigurierten Liste.

**Warum ist es relevant?** Allgemeine Beschriftungen verraten Lesern und Suchmaschinen wenig über das Ziel.

**Wie beheben?** Beschreibe das Linkziel mit einem kurzen, konkreten Ankertext.

## English

**What does it mean?** Internal links use a generic anchor phrase from the configured list.

**Why does it matter?** Generic labels give readers and search engines little information about the destination.

**How to fix** Replace the phrase with a concise description of the destination.
