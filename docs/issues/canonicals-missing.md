# Canonicals: Missing

Typ: Warning (T-W2) · Priorität: Medium (P-M1)

## Deutsch

**Was bedeutet das?** Die Seite nennt keine kanonische Adresse.

**Warum ist es relevant?** Ohne Canonical-Hinweis wählen Suchmaschinen die bevorzugte Fassung der Seite selbst, und die Signale von Duplikat-Varianten können sich auf mehrere Adressen verteilen.

**Wie beheben?** Im Head ein Canonical-Element ergänzen, das auf die bevorzugte Adresse der Seite zeigt. Für Seiten ohne Duplikate ist eine selbstverweisende Canonical-Angabe eine gute Voreinstellung.

## English

**What does it mean?** The page does not name a canonical address.

**Why does it matter?** Without a canonical hint, search engines choose the preferred version of the page on their own, and signals of duplicate variants may be spread over several addresses.

**How to fix** Add a canonical element to the head that points to the preferred address of the page. For pages without duplicates, a self-referencing canonical is a good default.
