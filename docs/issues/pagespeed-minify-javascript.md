# PageSpeed: Minify JavaScript

Typ: Opportunity (T-O2) · Priorität: Medium (P-M1)

## Deutsch

**Was bedeutet das?** JavaScript-Dateien enthalten Leerraum, Kommentare und lange Namen, die sich verkleinern lassen.

**Warum ist es relevant?** Unverkleinerte Skripte übertragen und parsen unnötige Bytes.

**Wie beheben?** Verkleinere Skripte im Build-Prozess und liefere sie komprimiert aus.

## English

**What does it mean?** JavaScript files contain whitespace, comments and long names that can be shrunk.

**Why does it matter?** Unminified scripts transfer and parse unnecessary bytes.

**How to fix** Minify scripts in the build process and serve them compressed.
