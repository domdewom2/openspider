# Response Codes: Internal Client Error (4XX)

Typ: Issue (T-I1) · Priorität: High (P-H1)

## Deutsch

**Was bedeutet das?** Die interne URL antwortet mit einem Client-Fehler im Bereich 4xx, etwa 404 (nicht gefunden) oder 410 (entfernt).

**Warum ist es relevant?** Besucher landen auf einer Fehlerseite, Links auf die Adresse führen ins Leere, und Suchmaschinen nehmen die Seite aus dem Index. Viele defekte Links wirken außerdem nachlässig gepflegt.

**Wie beheben?** Die Seite wiederherstellen, falls sie versehentlich entfernt wurde. Ist sie endgültig weg, die Adresse auf die passendste Ersatzseite weiterleiten und jeden internen Link, der noch darauf zeigt, entfernen oder aktualisieren.

## English

**What does it mean?** The internal URL answers with a client error status in the 4xx range, such as 404 not found or 410 gone.

**Why does it matter?** Visitors land on an error page, links to the address lead nowhere and search engines drop the page from their index. Many broken links also signal poor site maintenance.

**How to fix** Restore the page if it was removed by mistake. If it is gone for good, redirect the address to the closest replacement page and remove or update every internal link that still points to it.
