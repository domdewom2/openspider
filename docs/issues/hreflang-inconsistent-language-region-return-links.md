# Hreflang: Inconsistent Language & Region Return Links

Typ: Issue (T-I3) · Priorität: High (P-H2)

## Deutsch

**Was bedeutet das?** Ein Rückverweis verwendet einen anderen Code als die Selbstreferenz der Quellseite.

**Warum ist es relevant?** Widersprüchliche Codes machen die Zuordnung der Sprachvarianten uneindeutig.

**Wie beheben?** Verwende im ganzen Set denselben Sprach- und Regionscode für jede Seite.

## English

**What does it mean?** A return annotation uses a different code from the source page’s self annotation.

**Why does it matter?** Conflicting language assignments make the intended language set ambiguous.

**How to fix** Use the same language and region code for a page throughout the set.
