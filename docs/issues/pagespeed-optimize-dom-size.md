# PageSpeed: Optimize DOM Size

Typ: Opportunity (T-O2) · Priorität: Low (P-L1)

## Deutsch

**Was bedeutet das?** Die Seite hat ein sehr großes DOM, und Stil- oder Layoutberechnungen darauf dauern lange.

**Warum ist es relevant?** Große DOM-Bäume verteuern jede Berechnung und erhöhen den Speicherbedarf.

**Wie beheben?** Reduziere die Zahl der Elemente, rendere lange Listen nur ausschnittsweise und vermeide tiefe Verschachtelung.

## English

**What does it mean?** The page has a very large DOM and style or layout calculations on it take long.

**Why does it matter?** Large DOM trees make every calculation more expensive and increase memory use.

**How to fix** Reduce the number of elements, render long lists in windows and avoid deep nesting.
