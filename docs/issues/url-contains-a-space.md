# URL: Contains A Space

Typ: Issue (T-I2) · Priorität: Low (P-L1)

## Deutsch

**Was bedeutet das?** Die URL enthält ein Leerzeichen, das in kodierter Form als %20 erscheint.

**Warum ist es relevant?** Leerzeichen zerreißen Links in E-Mails und Texteditoren, und Werkzeuge schneiden die Adresse womöglich am Leerzeichen ab. Kodierte Adressen sind zudem schlecht lesbar.

**Wie beheben?** Leerzeichen in Datei- und Ordnernamen durch Bindestriche ersetzen und die alte Adresse dauerhaft auf die neue weiterleiten. Jeden internen Link mit der alten Schreibweise anpassen.

## English

**What does it mean?** The URL contains a space character, which shows up as %20 in the encoded form.

**Why does it matter?** Spaces break links in emails and text editors, and tools may cut the address off at the space. Encoded addresses are also hard to read.

**How to fix** Replace spaces with hyphens in file and folder names and redirect the old address permanently to the new one. Update every internal link that uses the old spelling.
