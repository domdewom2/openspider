# Hreflang: Missing Self Reference

Typ: Warning (T-W3) · Priorität: Low (P-L2)

## Deutsch

**Was bedeutet das?** Die Seite nennt Sprachvarianten, aber keine Annotation verweist auf sie selbst.

**Warum ist es relevant?** Eine Selbstreferenz macht die Zugehörigkeit zum Sprachsatz ausdrücklich.

**Wie beheben?** Ergänze eine Selbstreferenz mit dem passenden Sprachcode oder x-default.

## English

**What does it mean?** The page declares alternates but no annotation points to itself.

**Why does it matter?** A self reference makes membership in the language set explicit.

**How to fix** Add an annotation for this page with its language code or x-default.
