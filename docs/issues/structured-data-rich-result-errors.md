# Structured Data: Rich Result Validation Errors

Typ: Issue (T-I2) · Priorität: High (P-H2)

## Deutsch

**Was bedeutet das?** Bei mindestens einem erkannten Rich-Result-Feature fehlt eine Pflichteigenschaft oder ein Wert ist ungültig.

**Warum ist es relevant?** Ein Feature mit Fehlern kommt für die zugehörige erweiterte Darstellung in den Suchergebnissen nicht in Frage.

**Wie beheben?** Öffnen Sie die Details der strukturierten Daten, ergänzen Sie die fehlenden Pflichteigenschaften und korrigieren Sie ungültige Werte je genanntem Feature.

## English

**What does it mean?** At least one detected rich result feature lacks a required property or contains an invalid value.

**Why does it matter?** A feature with errors is not eligible for the corresponding enhanced search result presentation.

**How to fix** Open the structured data details, add the missing required properties and correct invalid values for each listed feature.
