# Hreflang: Noindex Return Links

Typ: Issue (T-I2) · Priorität: High (P-H2)

## Deutsch

**Was bedeutet das?** Ein Sprachziel hat eine wirksame noindex-Anweisung.

**Warum ist es relevant?** Eine ausgeschlossene Seite eignet sich nicht als indexierte Sprachalternative.

**Wie beheben?** Entferne unbeabsichtigtes noindex oder verwende eine indexierbare Ersatzseite.

## English

**What does it mean?** An alternate has an effective noindex directive.

**Why does it matter?** An excluded page cannot reliably serve as an indexed language alternative.

**How to fix** Remove unintended noindex directives or annotate an indexable replacement.
