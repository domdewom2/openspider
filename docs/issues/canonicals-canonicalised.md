# Canonicals: Canonicalised

Typ: Warning (T-W1) · Priorität: High (P-H2)

## Deutsch

**Was bedeutet das?** Die Seite nennt eine andere URL als ihre kanonische Adresse.

**Warum ist es relevant?** Die Seite selbst wird normalerweise nicht indexiert, weil die andere Adresse sie vertritt. Bei Duplikaten ist das gewollt, aber ein Fehler an dieser Stelle nimmt eine Seite aus der Suche.

**Wie beheben?** Prüfen, ob die genannte Adresse wirklich die bevorzugte Fassung ist und mit Status 200 antwortet. Soll die Seite unter ihrer eigenen Adresse gefunden werden, die Canonical-Angabe auf sie selbst setzen.

## English

**What does it mean?** The page names a different URL as its canonical address.

**Why does it matter?** The page itself will normally not be indexed, because the other address stands in for it. That is intended for duplicates, but a mistake here removes a page from search.

**How to fix** Check that the named address is really the preferred version and that it answers with status 200. If the page should be found under its own address, change the canonical element to point to itself.
