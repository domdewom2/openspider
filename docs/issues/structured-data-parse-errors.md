# Structured Data: Parse Errors

Typ: Issue (T-I1) · Priorität: High (P-H1)

## Deutsch

**Was bedeutet das?** Mindestens ein Block strukturierter Daten konnte nicht gelesen werden.

**Warum ist es relevant?** Syntaxfehler oder nicht auflösbare Typangaben verhindern, dass dieser Block zuverlässig ausgewertet wird. Andere lesbare Blöcke werden weiterhin erfasst.

**Wie beheben?** Öffnen Sie die Details der strukturierten Daten. Korrigieren Sie die gemeldete Stelle anhand von Zeile, Spalte und Ausschnitt und prüfen Sie die Seite erneut.

## English

**What does it mean?** At least one structured data block could not be read.

**Why does it matter?** Syntax errors or unresolved type identifiers prevent reliable interpretation of this block. Other readable blocks are still extracted.

**How to fix** Open the structured data details. Correct the reported location using its line, column and snippet, then check the page again.
