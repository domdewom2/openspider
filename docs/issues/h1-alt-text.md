# H1: Alt Text in h1

Typ: Warning (T-W2) · Priorität: Low (P-L1)

## Deutsch

**Was bedeutet das?** Eine H1 enthält ein Bild mit gefülltem Alternativtext.

**Warum ist es relevant?** Die Hauptüberschrift sollte den Seiteninhalt klar und in sinnvoller Reihenfolge vermitteln.

**Wie beheben?** Prüfe die Überschriftenreihenfolge und ob der Alternativtext des Bildes als Hauptüberschrift geeignet ist.

## English

**What does it mean?** An H1 contains an image with nonempty alternative text.

**Why does it matter?** The main heading should clearly describe the page content in a meaningful order.

**How to fix** Review heading order and whether the image alternative text is suitable as the main heading.
