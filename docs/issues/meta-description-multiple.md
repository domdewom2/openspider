# Meta Description: Multiple

Typ: Issue (T-I2) · Priorität: Medium (P-M1)

## Deutsch

**Was bedeutet das?** Die Seite enthält mehr als ein Meta-Description-Element.

**Warum ist es relevant?** Suchmaschinen verwenden nur eines davon, und man kann nicht sicher sein, welches. Die widersprüchlichen Einträge stammen meist von verschiedenen Plugins oder Vorlagen.

**Wie beheben?** Eine einzige Meta-Beschreibung im Head behalten und die anderen entfernen. Vorlagen, Plugins und Skripte prüfen, die das Element hinzufügen.

## English

**What does it mean?** The page contains more than one meta description element.

**Why does it matter?** Search engines will use only one of them and you cannot be sure which. The contradicting entries usually come from different plugins or templates.

**How to fix** Keep a single meta description in the head and remove the others. Check the templates, plugins and scripts that add the element.
