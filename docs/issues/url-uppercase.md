# URL: Uppercase

Typ: Warning (T-W2) · Priorität: Low (P-L1)

## Deutsch

**Was bedeutet das?** Die URL enthält Großbuchstaben im Pfad oder in der Abfrage.

**Warum ist es relevant?** Pfade unterscheiden auf vielen Servern zwischen Groß- und Kleinschreibung, daher ist dieselbe Seite unter mehreren Schreibweisen erreichbar. Das erzeugt Duplikate und Tippfehler in Links.

**Wie beheben?** Durchgängig kleingeschriebene Adressen verwenden. Varianten mit Großbuchstaben dauerhaft auf die kleingeschriebene Fassung weiterleiten und darauf achten, dass interne Links, Canonical-Angaben und Sitemaps die Kleinschreibung nutzen.

## English

**What does it mean?** The URL contains uppercase letters in its path or query.

**Why does it matter?** Paths are case sensitive on many servers, so the same page can be reached under several spellings. This creates duplicates and mistyped links.

**How to fix** Use lowercase addresses throughout. Redirect uppercase variants permanently to the lowercase version and make sure internal links, canonical elements and sitemaps use the lowercase form.
