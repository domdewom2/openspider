# Structured Data: Rich Result Validation Warnings

Typ: Opportunity (T-O2) · Priorität: Low (P-L1)

## Deutsch

**Was bedeutet das?** Bei mindestens einem erkannten Rich-Result-Feature fehlt eine empfohlene Eigenschaft.

**Warum ist es relevant?** Das Feature bleibt nutzbar, zusätzliche Angaben können die Darstellung im Suchergebnis aber vollständiger machen.

**Wie beheben?** Ergänzen Sie die empfohlenen Eigenschaften, soweit die Informationen auf der Seite vorhanden sind.

## English

**What does it mean?** At least one detected rich result feature lacks a recommended property.

**Why does it matter?** The feature remains eligible, but additional information could make the search result presentation more complete.

**How to fix** Add the recommended properties where the information is available on the page.
