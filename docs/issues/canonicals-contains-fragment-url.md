# Canonicals: Contains Fragment URL

Typ: Issue (T-I2) · Priorität: High (P-H2)

## Deutsch

**Was bedeutet das?** Eine Canonical-Zieladresse enthält ein Fragment, auch wenn hinter # kein Wert steht.

**Warum ist es relevant?** Fragmente bezeichnen Abschnitte innerhalb einer Ressource und können die Auswahl der kanonischen Adresse uneindeutig machen.

**Wie beheben?** Das Fragment aus der Canonical-Angabe entfernen und auf die vollständige bevorzugte Ressourcenadresse zeigen.

## English

**What does it mean?** A canonical target contains a fragment, including an empty value after #.

**Why does it matter?** Fragments identify sections within a resource and can make the canonical address ambiguous.

**How to fix** Remove the fragment and point to the complete preferred resource address.
