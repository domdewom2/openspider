# Structured Data: Validation Warnings

Typ: Opportunity (T-O2) · Priorität: Low (P-L1)

## Deutsch

**Was bedeutet das?** Mindestens ein Element strukturierter Daten verwendet noch das abgekündigte Vokabular data-vocabulary.org.

**Warum ist es relevant?** Suchdienste werten dieses Vokabular nicht mehr aus; das Markup bleibt daher wirkungslos.

**Wie beheben?** Ersetzen Sie die Elemente durch gleichwertige schema.org-Typen und -Eigenschaften und prüfen Sie die Seite erneut.

## English

**What does it mean?** At least one structured data item still uses the retired data-vocabulary.org vocabulary.

**Why does it matter?** Search services no longer evaluate this vocabulary, so the markup has no effect.

**How to fix** Replace the items with equivalent schema.org types and properties and check the page again.
