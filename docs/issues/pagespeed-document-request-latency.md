# PageSpeed: Document Request Latency

Typ: Opportunity (T-O2) · Priorität: Medium (P-M1)

## Deutsch

**Was bedeutet das?** Das HTML-Dokument selbst kommt verzögert an: Weiterleitungen, eine langsame Serverantwort oder fehlende Textkompression verlängern die Anfrage.

**Warum ist es relevant?** Jede Verzögerung beim Dokument verschiebt alle folgenden Schritte – erstes Rendern und größtes Element erscheinen später.

**Wie beheben?** Leite direkt auf die endgültige URL, beschleunige die Serverantwort (Caching, schnellere Datenbankabfragen) und liefere HTML komprimiert aus.

## English

**What does it mean?** The HTML document itself arrives late: redirects, a slow server response or missing text compression lengthen the request.

**Why does it matter?** Every delay on the document postpones all later steps, so first render and the largest element appear later.

**How to fix** Link straight to the final URL, speed up the server response (caching, faster queries) and serve HTML compressed.
