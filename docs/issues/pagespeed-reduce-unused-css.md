# PageSpeed: Reduce Unused CSS

Typ: Opportunity (T-O2) · Priorität: Medium (P-M1)

## Deutsch

**Was bedeutet das?** Ein großer Teil der geladenen CSS-Regeln wird auf der Seite nicht verwendet.

**Warum ist es relevant?** Ungenutzte Regeln verlängern Download und Stilberechnung.

**Wie beheben?** Entferne ungenutzte Regeln oder teile Stylesheets nach Seitentyp auf und lade nur, was die Seite braucht.

## English

**What does it mean?** A large share of the loaded CSS rules is not used on the page.

**Why does it matter?** Unused rules lengthen download and style calculation.

**How to fix** Remove unused rules or split stylesheets by page type and load only what the page needs.
