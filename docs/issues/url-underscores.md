# URL: Underscores

Typ: Opportunity (T-O1) · Priorität: Low (P-L1)

## Deutsch

**Was bedeutet das?** Die URL trennt Wörter mit Unterstrichen statt mit Bindestrichen.

**Warum ist es relevant?** Suchmaschinen lesen Bindestriche als Worttrenner, Unterstriche dagegen können Wörter zu einem langen Begriff verbinden, was den Abgleich der Adresse mit einer Suchanfrage erschwert.

**Wie beheben?** In neuen URLs Bindestriche verwenden. Eine bestehende Adresse nur umbenennen, wenn sich der Aufwand lohnt, die alte Adresse dauerhaft auf die neue weiterleiten und interne Links anpassen.

## English

**What does it mean?** The URL separates words with underscores instead of hyphens.

**Why does it matter?** Search engines read hyphens as word separators, while underscores may join words into one long term, which makes it harder to match the address to a search query.

**How to fix** Use hyphens in new URLs. Rename an existing address only when it is worth the effort, redirect the old address permanently to the new one and update internal links.
