# URL: Broken Bookmark

Typ: Issue (T-I2) · Priorität: Low (P-L1)

## Deutsch

**Was bedeutet das?** Das Fragment verweist auf keine bekannte Element-ID oder benannte Sprungmarke im erfolgreichen HTML-Ziel.

**Warum ist es relevant?** Besucher erreichen über diesen Link den gewünschten Abschnitt nicht.

**Wie beheben?** Korrigiere das Fragment auf der verlinkenden Seite oder stelle die passende ID auf dem Ziel wieder her. IDs unterscheiden Groß- und Kleinschreibung.

## English

**What does it mean?** The fragment points to no known element ID or named anchor in the successful HTML target.

**Why does it matter?** Visitors following the link cannot jump to the intended section.

**How to fix** Correct the fragment in the linking page or restore the matching ID on the target. IDs are case-sensitive.
