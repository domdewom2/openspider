# Links: Non-Indexable Page Inlinks Only

Typ: Warning (T-W2) · Priorität: High (P-H2)

Befüllt erst nach der Crawl-Analyse.

## Deutsch

**Was bedeutet das?** Nur nicht indexierbare Seiten verlinken intern auf diese indexierbare Seite.

**Warum ist es relevant?** Auffindbarkeit und interne Gewichtung hängen damit von ausgeschlossenen Seiten ab.

**Wie beheben?** Verlinke die Seite von einer passenden indexierbaren Seite.

## English

**What does it mean?** Only non-indexable pages provide internal hyperlinks to this indexable page.

**Why does it matter?** Discovery and internal authority may depend on pages that search engines exclude.

**How to fix** Link to the page from a relevant indexable page.
