# Canonicals: Invalid Attribute In Annotation

Typ: Issue (T-I2) · Priorität: High (P-H2)

## Deutsch

**Was bedeutet das?** Eine Canonical-Angabe enthält hreflang, lang, media oder type.

**Warum ist es relevant?** Diese Attribute können dazu führen, dass Suchmaschinen die Canonical-Angabe ignorieren.

**Wie beheben?** Diese Attribute vom Canonical-Element oder Link-Header entfernen; Sprachalternativen separat auszeichnen.

## English

**What does it mean?** A canonical annotation contains hreflang, lang, media or type.

**Why does it matter?** These attributes may cause search engines to ignore the canonical annotation.

**How to fix** Remove these attributes from the canonical element or Link header; declare language alternatives separately.
