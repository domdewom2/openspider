# Meta Keywords: Missing

Typ: Opportunity (T-O1) · Priorität: Low (P-L1)

## Deutsch

**Was bedeutet das?** Es wurde kein gefüllter Keywords-Wert gefunden.

**Warum ist es relevant?** Meta Keywords haben für viele Suchmaschinen keine Rankingwirkung.

**Wie beheben?** Prüfe, ob interne Systeme diese Angaben benötigen; andernfalls können sie entfallen.

## English

**What does it mean?** No nonempty meta keywords value was found on this page.

**Why does it matter?** Meta keywords have no ranking effect in many search engines.

**How to fix** Check whether internal systems need these values; otherwise they can be removed.
