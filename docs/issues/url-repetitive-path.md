# URL: Repetitive Path

Typ: Warning (T-W2) · Priorität: Low (P-L1)

## Deutsch

**Was bedeutet das?** Der Pfad enthält dasselbe nicht leere Segment mehrfach.

**Warum ist es relevant?** Wiederholungen können auf relative Links hinweisen, die immer längere Crawl-Pfade erzeugen.

**Wie beheben?** Prüfe die verlinkende Seite und korrigiere relative Pfade. Beabsichtigte Wiederholungen für unterschiedliche Inhalte können bestehen bleiben.

## English

**What does it mean?** The path contains the same non-empty segment more than once.

**Why does it matter?** Repeated segments can indicate relative links that create an expanding crawl path.

**How to fix** Review the linking page and correct relative paths. Keep deliberate repetitions when they represent distinct content.
