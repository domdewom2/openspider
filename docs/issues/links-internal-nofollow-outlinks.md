# Links: Internal Nofollow Outlinks

Typ: Warning (T-W1) · Priorität: Low (P-L1)

## Deutsch

**Was bedeutet das?** Die Seite enthält interne Links, die mit nofollow gekennzeichnet sind.

**Warum ist es relevant?** Nofollow an einem internen Link hält Linkwert von der Zielseite fern. Das ist manchmal gewollt, meist aber nur ein Überbleibsel aus Vorlagen oder Plugins.

**Wie beheben?** Das Attribut nofollow von internen Links entfernen, die Wert weitergeben sollen. Nur für Links auf Seiten behalten, die Sie bewusst nicht fördern wollen, etwa Anmeldeseiten.

## English

**What does it mean?** The page contains internal links marked with nofollow.

**Why does it matter?** Nofollow on an internal link keeps link value from flowing to the target page. That is sometimes intended, but usually only a leftover from templates or plugins.

**How to fix** Remove the nofollow attribute from internal links that should pass value. Keep it only for links to pages that you deliberately do not want to promote, such as login pages.
