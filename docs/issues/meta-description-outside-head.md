# Meta Description: Outside <head>

Typ: Issue (T-I2) · Priorität: Medium (P-M1)

## Deutsch

**Was bedeutet das?** Eine Beschreibung steht außerhalb des Dokumentkopfs.

**Warum ist es relevant?** Suchmaschinen können Beschreibungen außerhalb des Dokumentkopfs ignorieren.

**Wie beheben?** Verschiebe die Meta Description in den HTML-Dokumentkopf.

## English

**What does it mean?** A description is outside the document head.

**Why does it matter?** Search engines may ignore descriptions outside the document head.

**How to fix** Move the meta description into the HTML document head.
