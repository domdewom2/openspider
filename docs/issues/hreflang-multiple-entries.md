# Hreflang: Multiple Entries

Typ: Issue (T-I3) · Priorität: High (P-H2)

## Deutsch

**Was bedeutet das?** Ein Sprachcode kommt im Annotationssatz der Seite mehrfach vor.

**Warum ist es relevant?** Mehrfache Codes können einer Sprache mehrere Ziele zuordnen.

**Wie beheben?** Behalte eine Angabe je Code und gleiche HTML, HTTP-Header und Sitemap ab.

## English

**What does it mean?** A language code occurs more than once in the page’s annotation set.

**Why does it matter?** Repeated codes can assign several targets to one language.

**How to fix** Keep one annotation per code and reconcile HTML, HTTP and sitemap declarations.
