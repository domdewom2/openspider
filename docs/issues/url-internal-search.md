# URL: Internal Search

Typ: Warning (T-W2) · Priorität: Low (P-L1)

## Deutsch

**Was bedeutet das?** Die URL passt zu einem konfigurierten Suchmuster oder einem SearchAction-Muster auf der Seite.

**Warum ist es relevant?** Suchergebnisse können viele URL-Kombinationen mit ähnlichen oder wechselnden Inhalten erzeugen.

**Wie beheben?** Prüfe, ob Suchergebnisse gecrawlt und indexiert werden sollen. Passe Crawl-Regeln und Sucherkennungslisten an die Website an.

## English

**What does it mean?** The URL matches a configured internal search pattern or a SearchAction template on the page.

**Why does it matter?** Search results may create many combinations of URLs with overlapping or changing content.

**How to fix** Check whether search results should be crawled and indexed. Adjust crawl rules and the search detection lists to match the site.
