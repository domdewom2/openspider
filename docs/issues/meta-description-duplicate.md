# Meta Description: Duplicate

Typ: Opportunity (T-O1) · Priorität: Low (P-L1)

## Deutsch

**Was bedeutet das?** Mehrere Seiten tragen dieselbe Meta-Beschreibung.

**Warum ist es relevant?** Identische Beschreibungen lassen Suchergebnisse eintönig wirken und helfen Suchenden nicht, die passende Seite zu wählen.

**Wie beheben?** Für jede wichtige Seite eine eigene Beschreibung schreiben, die ihren Inhalt widerspiegelt. Bei vielen ähnlichen Seiten die Beschreibungen aus unterscheidenden Merkmalen zusammensetzen, statt einen Text wiederzuverwenden.

## English

**What does it mean?** Several pages carry the same meta description.

**Why does it matter?** Identical descriptions make search results look repetitive and do not help searchers to pick the right page.

**How to fix** Write a unique description for each important page that reflects its content. For many similar pages, build descriptions from distinguishing details instead of reusing one text.
