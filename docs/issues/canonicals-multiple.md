# Canonicals: Multiple

Typ: Warning (T-W2) · Priorität: Low (P-L1)

## Deutsch

**Was bedeutet das?** Die Seite nennt mehr als eine kanonische Adresse.

**Warum ist es relevant?** Suchmaschinen ignorieren womöglich alle, wenn sie nicht erkennen können, welche gemeint ist. Selbst gleichlautende Einträge sind fehleranfällig, weil spätere Änderungen sie auseinanderlaufen lassen können.

**Wie beheben?** Ein Canonical-Element behalten und die anderen entfernen. Prüfen, ob Seitenvorlage, ein Plugin und die HTTP-Header jeweils eines hinzufügen.

## English

**What does it mean?** The page names more than one canonical address.

**Why does it matter?** Search engines may ignore all of them when they cannot tell which one is meant. Even identical entries are error-prone, because later edits can make them diverge.

**How to fix** Keep one canonical element and remove the others. Check whether the page template, a plugin and the HTTP headers each add one.
