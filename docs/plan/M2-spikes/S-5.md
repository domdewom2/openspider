Reproduktion mit erzwungener Bridge (kein stiller Mock-Rückfall):

```sh
npm ci
npx --no-install playwright install webkit
cargo build --locked -p os-app --features e2e-bridge --bin os-app-bridge
OS_E2E_TRANSPORT=bridge OS_E2E_PROJECTS=webkit npm run -w apps/desktop e2e
```

Vite auf Port 1420 wird von `playwright.config.ts` gestartet; die Testfixture
startet `os-app-bridge` mit isoliertem Home und Loopback-WebSocket.
Auf Linux installiert der Workflow die Browser mit `--with-deps`.

**Entscheidung:** E2E-A mit Playwright-WebKit + Vite + os-app-bridge bleibt
der Frontend/Kern-Testweg auf macOS und Linux. Native Menü-, Fokus- und
Fensterverhalten werden weiterhin separat durch S-3/S-5b/S-6 geprüft.
