## Implementierungsentscheidungen

- SERP bleibt eine Engine-API; dieses Paket ändert keine Desktop-Feature-Oberfläche.
- Jede SERP-Zeile erhält einen privaten URN-Schlüssel, sodass auch doppelte oder
  fehlende Adressen eigenständige Entwürfe bleiben. Die sichtbare Adresse bleibt
  unverändert; leere Adressen heißen `Zeile N` (einschließlich Kopfzeile gezählt).
- Entwürfe nutzen eine synthetische HTML/200-Einstufung für die vorhandenen
  Element- und Duplikatfilter. HTTP-Header, Abrufzeitstempel und Transfermessungen
  werden nicht erfunden; die Engine meldet null HTTP-Abrufe. Ein erneuter Upload
  ersetzt das Fortsetzen oder erneute HTTP-Prüfen eines SERP-Datensatzes.
- Spider/List behalten bei ausgeschalteten Always-Follow-Optionen ihr Verhalten.
  Der Import nutzt dieselben Messfunktionen wie die HTML-Extraktion.

+/// One uploaded draft, in input order. Text is preserved verbatim.

+pub struct SerpRow {
+    pub url: String,
+    pub title: String,
+    pub description: String,

+/// Reads delimited TXT/CSV or an XLS/XLSX workbook (first sheet).
+pub fn read(path: &Path) -> Result<Vec<SerpRow>, EngineError> {
+    let ext = path
+        .extension()
+        .and_then(|s| s.to_str())
+        .unwrap_or("")
+        .to_ascii_lowercase();
+    if matches!(ext.as_str(), "xls" | "xlsx") {
+        use calamine::Reader;
+        let mut book = calamine::open_workbook_auto(path)
+            .map_err(|e| EngineError::Invalid(format!("SERP: {e}")))?;
+        let (_, sheet) = book
+            .worksheets()
+            .into_iter()
+            .next()
+            .ok_or_else(|| EngineError::Invalid("SERP: Kein Tabellenblatt".into()))?;
+        return from_rows(
+            sheet
+                .rows()
+                .map(|row| row.iter().map(ToString::to_string).collect())
+                .collect(),
+        );
+    }
+    let bytes = std::fs::read(path)?;
+    parse(&crate::list_input::decode_text(&bytes))
+}

+/// Parses CSV, semicolon-separated CSV or tab-delimited text, including quoted newlines.
+pub fn parse(text: &str) -> Result<Vec<SerpRow>, EngineError> {
+    let text = text.trim_start_matches('\u{feff}');
+    let delimiter = b",;\t"
+        .iter()
+        .copied()
+        .max_by_key(|d| {
+            text.lines()
+                .next()
+                .unwrap_or_default()
+                .bytes()
+                .filter(|b| b == d)
+                .count()
+        })
+        .unwrap_or(b',');
+    let mut reader = csv::ReaderBuilder::new()
+        .has_headers(false)
+        .flexible(true)
+        .delimiter(delimiter)
+        .from_reader(text.as_bytes());
+    let rows = reader
+        .records()
+        .map(|r| r.map(|r| r.iter().map(str::to_string).collect()))
+        .collect::<Result<Vec<_>, _>>()
+        .map_err(|e| EngineError::Invalid(format!("SERP: {e}")))?;
+    from_rows(rows)
+}

+fn from_rows(rows: Vec<Vec<String>>) -> Result<Vec<SerpRow>, EngineError> {
+    let header = rows.first().cloned().unwrap_or_default();
+    let column = |name: &str, aliases: &[&str]| {
+        header
+            .iter()
+            .position(|h| aliases.iter().any(|a| h.trim().eq_ignore_ascii_case(a)))
+            .ok_or_else(|| EngineError::Invalid(format!("SERP: Pflichtspalte {name} fehlt")))
+    };
+    let url = column("URL", &["URL", "Address"])?;
+    let title = column("Title / Titel", &["Title", "Titel", "Title 1"])?;
+    let description = column(
+        "Description / Beschreibung",
+        &["Description", "Beschreibung", "Meta Description 1"],
+    )?;
+    Ok(rows
+        .into_iter()
+        .skip(1)
+        .enumerate()
+        .map(|(i, row)| {
+            let get = |n| row.get(n).cloned().unwrap_or_default();
