## Empfehlungen und Festlegungen

- TECH-138: `HIGH_INTERNAL` zählt folgbare interne Hyperlink-Instanzen ohne
  Ressourcen und ohne Self-Links. Der Self-Link-Ausschluss ist eine
  OS-Festlegung, konsistent mit den übrigen Links-Zählern. Der Test
  `thresholds_count_follow_instances_without_resources_or_self_links` deckt sie ab.
- OUT-041/K2-27: `reason_text` verwendet `UncrawlableReason::from_str` (über
  `parse`) und `label()`. Das Modell besitzt die vollständige, typisierte
  Label-Zuordnung; unbekannte zukünftige DB-Werte bleiben als Rohwert erhalten.
  Test: `uncrawlable_export_uses_model_labels_for_every_known_reason_and_preserves_unknowns`.
- PERF-007: `CancelToken::on_cancel` registriert einen einmaligen Hook mit
  Lebensdauer-Guard. `with_sql_cancel` bindet ausschließlich den SQLite-
  Interrupt-Handle daran; der 5-ms-Polling-Thread entfällt. Drop entfernt den
  Hook und wartet auf eine eventuell laufende Ausführung, damit spätere
  Statements derselben Verbindung nicht versehentlich unterbrochen werden.
  Tests prüfen aktive SQL-Unterbrechung, Weiternutzung der Verbindung,
  wiederholten/vorherigen Abbruch und Freigabe der Registrierung.
- Die englischen Kommentare der Anchors-Tests wurden ins Deutsche übertragen.
- K2-28: aria-label zählt auch in OUT-036 nicht als Ankertext.
- K2-47: Nenner von `% of Total` sind HTML-2xx-Seiten.

## Fremdergänzungen (K2-61)

Die folgenden Ergänzungen dienen unmittelbar den entschiedenen D08-Befunden.
Vorhandene öffentliche Signaturen bleiben erhalten, keine neue Abhängigkeit
oder Lockfile-Änderung. Autorisierung: Auftrag dieser Fix-Runde einschließlich
additiver Fremdergänzungen und Umsetzung sämtlicher Review-Empfehlungen.

1. Bereits im Paket: `crates/os-analyze/src/details/mod.rs`, additiver
   Registry-Hook für Anchors nach TECH-146. Der generische Adapter reicht
   Optionen/Spaltentypen nicht weiter:

   ```diff
    pub fn detail_source(kind: DetailKind) -> (&'static str, DetailFn) {
   +    if let Some(source) = crate::tabs::links::detail_source(kind) {
   +        return source;
   +    }
   ```

2. `crates/os-model/src/enums.rs`, zusätzliche Methode ausschließlich an
   `UncrawlableReason`, OUT-041/K2-27:

   ```diff
   +impl UncrawlableReason {
   +    pub fn label(self) -> &'static str {
   +        match self { /* alle sieben bestehenden Varianten */ }
   +    }
   +}
   ```

3. `crates/os-model/src/cancel.rs`, additive Hook-Registrierung für PERF-007.
   `State`, Pause/Fortschritt und bisherige Token-Methoden behalten ihre
   Bedeutung. `cancel()` löst zusätzlich registrierte Hooks aus:

   ```diff
    pub struct CancelToken {
        state: Arc<(Mutex<State>, Condvar)>,
   +    hooks: Arc<Mutex<Vec<Weak<CancelHook>>>>,
    }
   +pub struct CancelRegistration(Arc<CancelHook>);
   +pub fn on_cancel(&self, callback: impl FnOnce() + Send + 'static) -> CancelRegistration
   ```

   Der Guard entfernt den Callback unter derselben Sperre, die dessen
   Ausführung schützt. Die Hook-Liste hält nur Weak-Referenzen und wird beim
   Registrieren bereinigt; beim Abbruch wird sie geleert. Die Datenbank-
   Verbindung bleibt auf ihrem Besitzer-Thread.

4. `crates/os-store/Cargo.toml`, additive Feature-Aktivierung für die vorhandene
   rusqlite-Abhängigkeit (TECH-141, Review-Befund 6):

   ```diff
    rusqlite.workspace = true
   +# TECH-141: benannte URL-Prädikate auf jeder Store-Verbindung.
   +rusqlite.features = ["functions"]
   ```

   Benannte SQL-Funktionen erfordern dieses Feature. Keine Versionsänderung,
   kein neues Crate; das eingefrorene Workspace-Manifest bleibt unverändert.
