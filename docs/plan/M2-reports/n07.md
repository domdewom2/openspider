**PAKET OFFEN.** Nach der ausdrücklich verbindlichen Abbruchregel (M2.md Abschnitt 2a/C10 und Paketauftrag) wurde die Umsetzung bei notwendigem Änderungsbedarf außerhalb der freigegebenen Teilbereiche gestoppt. Auch der Nachtrag K2-92 deckt die folgenden Registeränderungen nicht ab.

Der Nachtrag K2-92 erledigt die zuvor dokumentierten Besitzblocker für `UrlLimits::default()` und `external.rs`. Die erneute Prüfung zeigt die folgenden verbleibenden Registerblocker.

## Benötigte Besitzfreigabe

1. `crates/os-analyze/src/tabs/mod.rs`, `M2_FILTERS` außerhalb des freigegebenen `parity_filters`-Blocks, Zeilen 217 und 420–425:

```diff
-    ("Internal", "Flash", None, &[], false),
+    ("Internal", "Plugins", None, &[], false),
@@ Images / Missing Size Attributes
-        &["images.parse_inline_css_backgrounds"],
+        &[],
```

Grund: SQ-07/ONPAGE-023 benennt Plugins um; ONPAGE-179 hat keine Konfigurationsvoraussetzung. Die öffentliche Filtertabelle muss mit dem Produktregister übereinstimmen. `crates/os-analyze/tests/filters_registry.rs` prüft diese Tabelle gegen die Planregister.

2. `docs/plan/M2-filters.toml`, Images-Filter Zeile 156 außerhalb der freigegebenen Internal-Filter:

```diff
-  { id = "Missing Size Attributes", spec = "ONPAGE-179", kind = "post_crawl:Images", issue = true, requires = ["images.parse_inline_css_backgrounds"] },
+  { id = "Missing Size Attributes", spec = "ONPAGE-179", kind = "post_crawl:Images", issue = true },
```

Grund: G09 kann die Voraussetzung im Produkt nur entfernen, wenn das verbindliche Register entsprechend mitgezogen wird; sonst schlägt `filters_match_the_registry_files_in_id_order_kind_and_requirements` fehl.

3. `docs/plan/M1-filters.toml`, External-Filter: neben der freigegebenen Umbenennung Flash → Plugins sind zusätzliche Einträge erforderlich:

```diff
   { id = "Plugins", spec = "ONPAGE-026", kind = "live" },
+  { id = "Media", spec = "ONPAGE-026", kind = "live" },
+  { id = "Fonts", spec = "ONPAGE-026", kind = "live" },
+  { id = "XML", spec = "ONPAGE-026", kind = "live" },
```

Grund: SQ-07/ONPAGE-026 verlangt die eigenen, immer sichtbaren Filter auch in External. K2-92 erweitert den Produktdateibesitz auf `external.rs`, aber nicht den ausdrücklich auf Flash → Plugins beschränkten Registerbesitz. Ohne zusätzliche Registereinträge widersprechen die Produktfilter dem dauerhaften Registertest. Die endgültige Reihenfolge muss mit `external.rs` übereinstimmen.
