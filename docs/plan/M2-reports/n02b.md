# M2-N02b – Vergleichsansicht auf DataGrid

Stand: 28.10.2026, Branch `m2/n02b`. Umsetzung nach K2-74 / Auflage N02b-1.

## Umsetzung

- `ComparisonTable.tsx` und `ComparisonLinks.tsx` verwenden das gemeinsame DataGrid. Grid-Dateien und die Haupttabelle bleiben unverändert.
- `ComparisonGrid.tsx` adaptiert die vorhandenen Vergleichsseiten über `ViewDataSource` und `SelectionModel`. Die bestehenden 100-Zeilen-Seiten, Gesamtzahlen, Filter, CSV-Inhalte und Rohwertdarstellung bleiben erhalten; insbesondere keine Rundung numerischer Vergleichswerte durch die allgemeine Grid-Formatierung.
- Dasselbe `ColumnsMenu` wie in der Haupttabelle: Spalten ein-/ausblenden, umordnen, Breite im Grid ändern und zurücksetzen. Einstellungen bleiben während Paging, Sortierung und Filterwechsel je Spaltenschema innerhalb der montierten Vergleichsansicht erhalten.
- Spaltenköpfe sortieren über die Vergleichsabfrage im Backend, inklusive Rückkehr auf Seite 1; Exporte übernehmen die Sortierung. Bei Change Detection bleibt die bestehende Sortierfunktion erhalten.
- Auswahl einer URL öffnet das vorhandene Detail einschließlich Partner-ID und Crawl-Seite. Die Markierung folgt der externen URL-Auswahl. Linkzeilen haben eine eigene Auswahl mit stabilen Schlüsseln; diese sind keine URL-IDs und werden nicht an die URL-Detailauswahl weitergereicht.
- Neue Beschriftung der Linktabelle in `features/compare/i18n/{de,en}.ftl`; bestehende Spaltenmenütexte werden wiederverwendet.

## U23-E2E-Befund

`apps/desktop/e2e/compare/bridge.spec.ts:51`, beide Engines: `getByRole("table", {name:"Comparison table", exact:true})` findet nach der geforderten DataGrid-Umstellung kein Element. Der Playwright-Fehlerkontext enthält stattdessen `grid "Comparison table"` mit vier echten Crawl-Zeilen. Die Crawls und das Öffnen der Vergleichssitzung liefen vorher erfolgreich.

U23 muss die Selektoren auf `grid`/`gridcell` und Auswahl/Sortierung auf die Grid-Gesten umstellen. Spätere Stellen derselben Datei verwenden ebenfalls alte `table`-/`cell`-/URL-Button-Selektoren. Die E2E-Dateien wurden entsprechend Besitzregel nicht geändert; der Ablauf hinter dem ersten fehlerhaften Selektor ist daher hier nicht vollständig geprüft. Traces und Fehlerkontexte liegen außerhalb des Worktrees im temporären Prüfverzeichnis `openspider-n02b-e2e-*`.

## Abweichungen und offene Punkte

- Die Frontend-Gesamtprüfung aus Schritt 5 ist grün. Offen für U23 bleibt die oben dokumentierte E2E-Anpassung.
- Die Vergleichsansicht behält ihr bisheriges Paging; das Grid virtualisiert jeweils die gelieferte Seite. Spaltenzustände werden innerhalb der Ansicht gehalten und nicht als neue dauerhafte App-Einstellung gespeichert.
- `Comparison Status` und `Previous Address` sind einblendbar/umordbar, aber nicht sortierbar: Der bestehende Backend-Vertrag ergänzt sie erst nach der normalen URL-Abfrage. Alle anderen gelieferten Spalten sowie die Change-Detection- und Linkspalten verwenden die verfügbare Backend-Sortierung. Kein weiterer Backend-Umbau außerhalb der Freigabe.
- Der macOS-Linker meldet beim Rust-Test und Bridge-Build `__eh_frame section too large (max 16MB)`; Builds erfolgreich. Keine Anpassung von Build-Konfiguration oder fremdem Code zur Unterdrückung dieser Warnung.
- Keine vollständige Rust-Workspace-/Clippy-/CI-Matrix-Prüfung in diesem Frontend-Paket; ausgeführt wurden die ausdrücklich verlangte Frontend-Gesamtprüfung und der gezielte Rust-Test.

+fn sort_link_rows(rows: &mut [(i64, Vec<Value>)], index: usize, dir: SortDir) {
+    rows.sort_by(|a, b| {
+        let cmp = match (&a.1[index], &b.1[index]) {
+            (Value::Null, Value::Null) => std::cmp::Ordering::Equal,
+            (Value::Null, _) => std::cmp::Ordering::Less,
+            (_, Value::Null) => std::cmp::Ordering::Greater,
+            (Value::Int(x), Value::Int(y)) => x.cmp(y),
+            (Value::Float(x), Value::Float(y)) => x.total_cmp(y),
+            (Value::Bool(x), Value::Bool(y)) => x.cmp(y),
+            (Value::Text(x), Value::Text(y)) => x.cmp(y),
+            (x, y) => format!("{x:?}").cmp(&format!("{y:?}")),
+        };
+        (if dir == SortDir::Desc { cmp.reverse() } else { cmp }).then_with(|| a.0.cmp(&b.0))
