## Schnittstellenbedarf (für I02 … I05 / N02)

1. **Property-Listen (INTEG-090, INTEG-110):** `M2.md` 3.6a kennt keinen Command für GA4-`accountSummaries`
   (Konten, Properties, Web-Datenstreams mit Hostname) und Search-Console-`sites.list` (Site-URL, Berechtigungsstufe).
   Vorschlag: `api.properties { kind, accountId? }` → `Ga4Account[]` bzw. `GscSite[]` (Formen in
   `features/integrations/properties.ts`). Die UI nimmt einen Lader über `registerPropertyCatalog` an; bis dahin
   manuelle Eingabe der Kennung.
2. **Datenstream (INTEG-090):** `Ga4Config` hat kein Feld für den Stream. Die UI sendet bereits `api.ga4.stream`
   (Stream-ID); der Kern verwirft das unbekannte Feld derzeit stillschweigend (kein `deny_unknown_fields`). Bedarf:
   `api.ga4.stream: Option<String>` und Hostnamen-Filter im Abruf (I02).
3. **Ebene „Exact URL (HTTP + HTTPS)“ (INTEG-150):** `ApiLevel` kennt nur `url`, `subdomain`, `domain`. Die Ebene
   erscheint deaktiviert („Noch nicht verfügbar“). Außerdem speichert `LinkMetricsConfig` Ebenen und Metriken als zwei
   Listen (Kreuzprodukt), nicht „je Metrik Ebenen“ – die UI zeigt deshalb eine Ebenen- und eine Metrikauswahl plus die
   entstehenden Spalten.
4. **PSI lokal (INTEG-130):** `api.connect` verlangt für Nicht-Google-Quellen einen Schlüssel (`err-api-key`). Für
   Quelle Lokal sendet die UI `api.connect` ohne Schlüssel; bis I04 das annimmt, endet der Versuch mit
   `Fehler: Bitte einen API-Schlüssel eingeben.`
5. **Optionen INTEG-152 … 154** (Majestic-Index Fresh/Historic, Ahrefs-Land/Volumen, Moz-Kontotyp) haben keine Felder in
   `LinkMetricsConfig`; nicht Teil der `extra_spec_ids`, daher nicht umgesetzt.

## Offene Fragen / Hinweise an den Planer

- **Ahrefs-Anmeldung:** UI-070/INTEG-153 verlangen OAuth („Mit Ahrefs anmelden“, kein Schlüsselfeld); `api.list`
  meldet für Ahrefs `auth: "apiKey"`. Die UI folgt dem Kernwert (`auth`) und zeigt bei `oauth` die Anmeldeschaltfläche
  ohne Schlüsselfeld – sie stellt automatisch um, wenn I05 `oauth` meldet.
- **Abbrechen während `Verbinde…`:** INTEG-001 erlaubt keinen Übergang `Verbinde…` → `Nicht verbunden`; die UI bietet
  deshalb keinen Abbruch. Bei OAuth wartet der Kern bis zu 5 Minuten auf den Browser-Rückruf. Falls ein Abbruch
  gewünscht ist (der Kern unterstützt `op.cancel`), müsste die Spec den Übergang ergänzen.
- **Metrik-Kennungen:** Die gespeicherten Kennungen in `api.<linkmetrik>.metrics` folgen den Feldnamen der
  Anbieter-APIs (z. B. `TrustFlow`, `domain_rating`, `domain_authority`; Liste in `sources.ts`). I05 sollte sie
  übernehmen oder eine verbindliche Liste vorgeben.
- **Fluent-Schlüssel:** Das Feature definiert die Bezeichnungen `api-<kind>` (Labels aus `api.list`/`api.status`) sowie
  die Kernmeldungen `err-api-*`, `notice-api-*`, `op-api-*`. Definiert ein paralleles Paket (z. B. U22) dieselben
  Schlüssel, meldet die i18n-Prüfung eine Doppelung; dann bitte beim Merge eine Quelle behalten.
- **Platzierung:** Der `IntegrationsHeaderSlot` sitzt vorläufig im Gerüst-Header; Modusumschaltung und Start-URL
  meldet U03 über `setApiMode`/`setCrawlUrl`.
