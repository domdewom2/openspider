# Documentation map

- [Contributor handbook](handbook/src/introduction.md): setup, architecture, current decisions, tests, CI/release and contribution process. [Table of contents](handbook/src/SUMMARY.md); [mdBook configuration](handbook/book.toml).
- [Architecture](ARCHITECTURE.md): core principles and layer responsibilities.
- [Specification index](spec/README.md): requirements, IDs and milestone scope.
- [M1 plan](plan/M1.md) and [M2 plan](plan/M2.md): work packages, dependencies, acceptance and K-/K2-decisions.
- [Release operations](release/macos-signing.md): maintained macOS release procedure.
- [Issue documentation](issues/README.md): issue catalog guide.

Start contributing with [CONTRIBUTING.md](../CONTRIBUTING.md). Build the handbook from the repository root with `~/.cargo/bin/mdbook build docs/handbook`; output stays under the ignored `docs/handbook/book/` directory.
