# OpenSpider – Funktionsspezifikation (Clean-Room)

Quelle: öffentliche Dokumentation, Release-Notes und beobachtbares Verhalten des Referenzprodukts (Screaming Frog SEO Spider 24.3).
Regeln:
- Verhalten in eigenen Worten beschreiben, keine Textpassagen kopieren, kein Code/Bytecode des Referenzprodukts.
- Jede Funktion hat eine ID `<BEREICH>-<NNN>` (z. B. `CRAWL-001`), Priorität P0 (MVP) / P1 (Parität) / P2 (später) und prüfbare Akzeptanzkriterien.

## Format je Funktion

### CRAWL-001 Titel
- **Priorität:** P0
- **Beschreibung:** …
- **Eingaben/Konfiguration:** …
- **Ausgabe (Spalten/Filter/Export):** …
- **Akzeptanzkriterien:** 
  - [ ] …
- **Testfixture:** welche Testseite das Verhalten prüft
